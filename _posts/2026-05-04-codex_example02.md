ChatGPT에 엑셀 파일을 올리면 결과를 "알려준다". 전화번호 형식이 제각각인 고객 데이터를 붙여넣으면 "이 형식으로 바꾸면 됩니다"라는 답변이 돌아온다. 직접 고쳐주지 않는다. 내가 그 결과를 받아서 수식을 짜거나, 복사해서 하나씩 붙여넣거나, 결국 손으로 고쳐야 한다.

**Claude Code는 다르다.** "전화번호 형식을 010-0000-0000으로 통일하고, 저장해줘"라고 지시하면 파일을 직접 열어서 수정하고 저장까지 완료한다. 내가 할 일은 결과 파일을 열어서 확인하는 것뿐이다.

단, 엑셀 처리에는 ChatGPT와 다른 종류의 주의사항이 있다. 이 가이드는 실습 방법과 함께 그 주의사항을 정직하게 정리한다.

---

## 1. 시작 전 반드시: 백업부터 한다

엑셀 파일을 다루기 전에 이 경고를 먼저 읽는다.

> ⚠️ **원본 파일 손상 가능성이 있다**
>
> Claude Code는 엑셀 파일을 수정할 때 **openpyxl**이라는 라이브러리를 사용한다. 단순한 데이터 파일에서는 문제가 없지만, 복잡한 수식, 매크로(`.xlsm`), 피벗 테이블, 조건부 서식이 많은 파일에서는 수정 후 Excel이 "파일이 손상됐습니다"라고 경고를 표시하거나 일부 내용이 사라지는 경우가 실제로 보고됐다.
>
> **실습 전 반드시 원본 파일을 다른 이름으로 복사해 둔다.**  
> 윈도우: 파일 선택 → `Ctrl+C` → 같은 폴더에서 `Ctrl+V` (복사본 자동 생성)  
> 맥: 파일 선택 → `Command+D` (복제)
>
> 복사본이 있으면 무슨 일이 생겨도 돌아갈 수 있다.

이 주의사항을 확인했다면 아래로 내려간다.

## 2. 파일 형식별 처리 안전도

엑셀 파일이라고 다 같은 엑셀이 아니다. 파일 확장자를 확인하고 아래 표를 참고한다.

| 파일 형식 | 설명 | 처리 안전도 | 권장 방법 |
|---|---|---|---|
| `.csv` | 쉼표로 구분된 텍스트 | ⭐⭐⭐ 최적 | 데이터 정제에 가장 안전 |
| `.xlsx` (단순 데이터) | 수식·서식 없는 기본 엑셀 | ⭐⭐⭐ 안전 | 백업 후 진행 |
| `.xlsx` (수식 포함) | SUM, VLOOKUP 등 수식 있음 | ⭐⭐ 조건부 | 백업 필수. 수식 변경 요청은 주의 |
| `.xlsx` (피벗·차트 포함) | 피벗 테이블, 차트 시트 | ⭐ 제한적 | 데이터 시트만 별도 저장 후 처리 |
| `.xlsm` | 매크로 파일 | ✗ 권장하지 않음 | Claude Code로 처리 금지. 손상 위험 높음 |
| `.xls` | 구버전 엑셀 (2003 이하) | ✗ 읽기만 가능 | `.xlsx`로 변환 후 처리 |

**가장 안전한 흐름:** 원본 → `.csv`로 저장 → Claude Code로 처리 → 결과 `.csv`를 엑셀에서 열기

복잡한 서식이나 수식이 필요 없는 데이터 정제 작업이라면 `.csv`를 중간 단계로 쓰는 것이 가장 안정적이다.

## 3. 샘플 파일 준비 — 지금 파일이 없어도 따라할 수 있다

실습용 샘플 파일을 5분 안에 만들 수 있다. 아래 내용을 복사해서 메모장(윈도우) 또는 텍스트 편집기(맥)에 붙여넣고 `customer_data.csv`로 저장한다.

```
이름,부서,전화번호,이메일,입사일
김민준,마케팅,01012345678,minjun@company.com,2023-03-15
이서연,영업,010-9876-5432,seoyeon@company.com,2022-11-01
박도윤,마케팅,010.8765.4321,,2024-01-20
최아린,인사,01023456789,arin@company.com,2023-03-15
정하은,영업,,haen@company.com,2021-07-08
김민준,마케팅,01012345678,minjun@company.com,2023-03-15
윤시우,기획,010-7654-3210,siwoo@company.com,2024-06-01

```

이 파일에는 정제가 필요한 대표적인 문제들이 모두 들어있다.

- 전화번호 형식 3가지 혼재 (`01012345678`, `010-9876-5432`, `010.8765.4321`)
- 빈 셀 (정하은의 전화번호, 박도윤의 이메일)
- 중복 행 (김민준, 이서연 각 2회 등장)

## 4. Claude Code 실행 — 이전 편 설치 완료 기준

1편에서 Claude Code를 이미 설치하고 로그인했다면 바로 시작할 수 있다.

**PowerShell(윈도우) 또는 터미널(맥)을 열고 파일이 있는 폴더로 이동한다.**

```bash
# 윈도우 예시
cd "C:\Users\홍길동\Documents\data"

# 맥 예시
cd /Users/honggildong/Documents/data
```

파일이 있는지 확인한다.

```bash
# 윈도우
dir

# 맥
ls
```

`customer_data.csv` 파일이 보이면 올바른 위치에 있는 것이다.

**Claude Code를 실행한다.**

```bash
claude
```

프롬프트(`>`)가 나타나면 준비가 됐다.

## 5. 실습 1 — 고객 데이터 3가지 문제 한 번에 정제

다음 프롬프트를 그대로 붙여넣는다.

```
customer_data.csv 파일을 열어서 다음 세 가지를 처리해줘.

1. 전화번호 형식 통일
   - 모든 전화번호를 010-0000-0000 형식으로 바꿔줘.
   - 예: 01012345678 → 010-1234-5678
   - 전화번호가 비어있는 셀은 "미등록"으로 채워줘.

2. 이메일 빈 셀 처리
   - 이메일이 비어있는 셀은 "미등록"으로 채워줘.

3. 중복 행 제거
   - 이름과 부서가 동일한 행이 중복되면 첫 번째 행만 남기고 나머지는 삭제해줘.

처리가 끝나면 customer_data_clean.csv로 저장해줘.
원본 customer_data.csv는 그대로 유지해줘.
```

Enter를 누르면 Claude Code가 작업을 시작한다. 터미널에 진행 과정이 표시된다.

```
Reading customer_data.csv...
Processing phone numbers...
Filling missing emails...
Removing duplicate rows...
Saving customer_data_clean.csv...
Done. 2 duplicates removed, 2 phone numbers formatted, 1 email filled.
```

완료 후 `customer_data_clean.csv` 파일이 같은 폴더에 생성됐는지 확인한다.

## 6. 실습 2 — 부서별 집계표 자동 생성

데이터 정제가 끝난 파일을 바탕으로 집계표를 만드는 실습이다. 같은 Claude Code 세션에서 이어서 입력한다.

```
customer_data_clean.csv를 읽고
부서별로 직원 수를 계산해서
summary_by_dept.csv 파일로 저장해줘.
표에는 부서명, 직원 수, 전체 대비 비율(%)을 포함해줘.
```

결과 파일이 생성되면 엑셀에서 열어서 확인한다.

## 7. 실전 프롬프트 모음

상황별로 바로 복사해서 쓸 수 있는 프롬프트다.

**날짜 형식 통일**

```
sales_data.csv 파일의 날짜 컬럼을 모두 YYYY-MM-DD 형식으로 통일해줘.
예: 2026.05.01, 05/01/2026, 2026년5월1일 → 2026-05-01
변환이 안 되는 셀은 "형식오류"로 표시해줘.
처리된 파일은 sales_data_clean.csv로 저장해줘.
```

**특수문자 및 공백 제거**

```
contact_list.csv 파일의 이름 컬럼에서
앞뒤 공백, 괄호, 점(.)을 제거해줘.
예: "  홍길동 ." → "홍길동"
수정된 파일은 contact_list_clean.csv로 저장해줘.
```

**조건부 분류 컬럼 추가**

```
employee.csv 파일을 읽고
입사일 기준으로 근속 연수를 계산해서
"연차" 컬럼을 추가해줘.
근속 3년 미만은 "신입", 3~7년은 "중급", 7년 이상은 "시니어"로 분류해줘.
결과는 employee_with_level.csv로 저장해줘.
```

**여러 파일 합치기**

```
monthly_sales 폴더 안의 모든 .csv 파일을 읽어서
하나의 파일로 합쳐줘.
각 행에 출처 파일 이름을 "월" 컬럼으로 추가해줘.
합쳐진 파일은 annual_sales.csv로 저장해줘.
```

**금액 컬럼 정제**

```
orders.csv 파일의 금액 컬럼에서
"원", "₩", 쉼표를 제거하고 숫자만 남겨줘.
예: "₩1,500,000원" → 1500000
수정된 파일은 orders_clean.csv로 저장해줘.
```

## 8. `.xlsx` 파일을 직접 처리해야 할 때

서식이나 색상이 있는 엑셀 파일을 직접 수정해야 한다면 아래 순서를 따른다.

**Step 1. 원본 백업**
파일을 복제해서 `원본_백업_날짜.xlsx`로 저장한다.

**Step 2. 처리 전 상태 확인**
파일을 닫고, Excel이 완전히 꺼져 있는지 확인한다.

**Step 3. 프롬프트에 안전 조건 명시**

```
customer_list.xlsx 파일을 열어서
A열의 전화번호 형식을 010-0000-0000으로 통일해줘.

주의사항:
- 기존 수식은 건드리지 말아줘.
- 조건부 서식은 유지해줘.
- 수정된 파일은 customer_list_updated.xlsx로 새로 저장해줘.
- 원본 파일은 절대 덮어쓰지 말아줘.
```

**Step 4. 결과 파일 검증**
Excel을 열어서 "파일이 손상됐습니다"라는 경고가 나오는지 확인한다. 경고가 나오면 백업 파일을 사용한다.

## 9. 자주 하는 실수와 해결법

**"파일을 찾을 수 없습니다" 오류**

현재 터미널 위치가 파일과 다른 폴더에 있는 경우다. `ls`(맥) 또는 `dir`(윈도우)로 파일 목록을 확인하고, 파일이 보이지 않으면 `cd` 명령어로 파일이 있는 폴더로 이동한다.

**전화번호가 앞자리부터 잘리는 경우**

CSV를 엑셀에서 열면 `010-1234-5678`을 숫자로 인식해서 앞자리 0이 사라진다. 이것은 Claude Code의 문제가 아니라 Excel의 셀 형식 설정 문제다. 해당 컬럼을 선택하고 셀 서식을 "텍스트"로 변경한 뒤 다시 열면 해결된다.

**한글이 깨지는 경우**

CSV 파일의 인코딩이 다른 경우다. 프롬프트에 아래 문장을 추가한다.

```
파일 인코딩은 UTF-8로 저장해줘.
```

이미 저장된 파일이 깨진다면 메모장으로 파일을 열고 "다른 이름으로 저장 → 인코딩 UTF-8"로 다시 저장한 뒤 다시 시도한다.

**이전 작업을 이어서 하고 싶을 때**

```bash
claude --resume
```

## 10. ChatGPT와 무엇이 다른가

| 상황 | ChatGPT | Claude Code |
|---|---|---|
| 전화번호 형식 통일 | "이렇게 하면 됩니다" 안내만 | 파일을 직접 열어서 수정 후 저장 |
| 중복 제거 결과 | 결과 텍스트로 출력 | 새 파일로 자동 저장 |
| 여러 파일 합치기 | 파일마다 개별 처리 필요 | 폴더 전체를 한 번에 처리 |
| 원본 보호 | 해당 없음 | 원본 유지 + 새 파일 저장 지시 가능 |

핵심 차이는 하나다. ChatGPT는 어떻게 해야 하는지를 알려준다. Claude Code는 실제로 해준다.
