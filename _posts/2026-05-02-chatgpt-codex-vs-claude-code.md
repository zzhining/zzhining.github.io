AI 코딩 도구 시장이 빠르게 정리되고 있다. 선택지는 많지만 결국 자주 거론되는 이름은 두 개다. OpenAI의 **Codex**와 Anthropic의 **Claude Code**. 두 도구를 단순히 '어느 쪽이 더 낫다'는 식으로 비교하는 글은 이미 넘친다. 이 글에서는 다르게 접근한다. 2026년 5월 기준 두 도구의 핵심 기능과 차이점을 정리하고, 개발자가 아닌 일반 직장인 관점에서 어떤 도구를 어떤 상황에서 써야 하는지 판단 기준을 제시한다.

## 1. 두 도구, 설계 철학부터 다르다

비교 전에 먼저 짚어야 할 것이 있다. 두 도구는 출발점이 다르다.

**OpenAI Codex**는 클라우드 우선 설계다. 작업을 요청하면 격리된 클라우드 샌드박스 환경에서 처리된다. 내 로컬 컴퓨터가 아닌 OpenAI 서버가 코드를 실행한다. 덕분에 여러 작업을 동시에 병렬로 처리하거나, 내가 다른 일을 하는 동안 에이전트가 백그라운드에서 작업을 완료하는 방식이 자연스럽다. 접근 경로도 다양하다. 웹(`chatgpt.com/codex`), CLI, VS Code 확장, 데스크탑 앱(macOS·Windows) 모두 지원한다.

**Claude Code**는 로컬 터미널 우선 설계다. 내 컴퓨터 안에서 파일을 직접 읽고, 명령어를 실행하고, 코드를 수정한다. 추론 과정을 실시간으로 보여주면서 위험한 작업 전에는 승인을 요청한다. 코드베이스 전체를 한 번에 읽는 대규모 컨텍스트 처리가 강점이다.

한 문장으로 요약하면 이렇다. Codex는 "속도와 병렬 처리", Claude Code는 "정확도와 로컬 제어"를 우선순위에 뒀다.

## 2. 2026년 5월 기준 최신 현황

**Codex 주요 업데이트 (2026년 4월 기준)**

2026년 4월 16일, OpenAI는 대규모 업데이트를 발표했다. 핵심 변경 사항은 다음과 같다.

- 기본 모델: GPT-5.5 (ChatGPT 계정 로그인 시 사용 가능)
- 컴퓨터 사용(Computer Use): Mac 앱을 직접 클릭·타이핑하며 조작. 여러 에이전트 동시 운영
- 인앱 브라우저: 페이지에 직접 주석을 달아 에이전트에 지시
- 이미지 생성: gpt-image-1.5 기반 목업, UI 시안 생성
- 메모리: 개인 워크플로우, 기술 스택 기억
- 자동화(Automations): 며칠에 걸친 장기 작업 스케줄링
- 90개 이상 플러그인: Microsoft Suite, Jira, GitLab, Slack 등 연동
- Windows 네이티브 지원 (2026년 3월 4일부터)

**Claude Code 주요 현황 (2026년 5월 기준)**

- 기반 모델: Claude Opus 4.7 (최신), Sonnet 계열
- 로컬 파일 직접 접근 및 실행
- 26개 라이프사이클 훅 지원: 자동화 정책 세밀 제어
- 서브에이전트 병렬 실행
- MCP 원클릭 커넥터: 다양한 외부 서비스 연동

## 3. 핵심 기능 비교표

| 항목 | Codex (OpenAI) | Claude Code (Anthropic) |
|---|---|---|
| 실행 방식 | 클라우드 샌드박스 | 로컬 터미널 |
| 기본 모델 | GPT-5.5 | Claude Opus 4.7 |
| 코드 품질 (블라인드 리뷰) | 25% 선호 | 67% 선호 |
| 속도·비용 효율 | 높음 (약 4배 저렴) | 상대적으로 높은 토큰 소모 |
| 병렬 작업 처리 | 강점 | 제한적 |
| 컴퓨터 사용(Computer Use) | 제한적 (macOS, 출시 중) | 더 강력함 |
| 컨텍스트 윈도우 | 272K (기본), 1.05M (롱컨텍스트) | 대용량 지원 |
| 비개발자 접근성 | 웹·앱 UI 제공으로 낮음 | CLI 중심으로 더 높음 |
| 플러그인 생태계 | ChatGPT 생태계 전체 활용 | MCP 원클릭 커넥터 강점 |
| 가격 시작점 | $20/월 (Plus) | $20/월 (Pro) |
| 요금제 | Plus $20 / Pro $100 | Pro $20 / Max $100·$200 |

한 가지 흥미로운 사실은 두 도구가 서로를 배척하지 않는다는 점이다. OpenAI가 공식 Codex 플러그인을 Claude Code 안에서 작동하게 만들었다. Claude Code 세션 내에서 특정 작업만 Codex에 위임하는 방식이 실제로 사용되고 있다.

## 4. 자주 사용하는 명령어 정리

**Codex CLI 핵심 명령어**

| 명령어 | 기능 |
|---|---|
| `codex` | 인터랙티브 세션 시작 |
| `codex "지시 내용"` | 프롬프트와 함께 바로 시작 |
| `codex exec "지시"` | 비대화형 실행 (자동화용) |
| `codex resume` | 이전 세션 이어서 시작 |
| `codex resume --last` | 가장 최근 세션 바로 재개 |
| `codex update` | 최신 버전 업데이트 |

**세션 내 슬래시 명령어**

| 명령어 | 기능 |
|---|---|
| `/model` | 모델 변경 |
| `/review` | 코드 리뷰 요청 |
| `/clear` | 채팅 초기화 |
| `/copy` | 최근 출력 복사 |
| `/exit` | 세션 종료 |

**Claude Code 핵심 명령어**

| 명령어 | 기능 |
|---|---|
| `claude` | 인터랙티브 세션 시작 |
| `claude "지시 내용"` | 바로 프롬프트 실행 |
| `claude -p "지시"` | 단발성 비대화형 실행 |
| `/review` | 코드 리뷰 |
| `/clear` | 대화 초기화 |
| `/memory` | 메모리 설정 확인 |
| `/cost` | 현재 세션 토큰 비용 확인 |

## 5. 비개발자·일반 직장인 실무 활용 사례

두 도구 모두 코딩 지식 없이도 활용 가능하지만, 접근 경로가 다르다.

**Codex를 선택할 때 유리한 상황**

- 이미 ChatGPT를 사용 중이라면 추가 비용 없이 `chatgpt.com/codex`에서 바로 시작
- 여러 작업을 동시에 걸어두고 결과를 나중에 확인하고 싶을 때
- Microsoft Suite 플러그인으로 Excel, Outlook과 연동하는 업무 자동화

*사례 1: HR 담당자*  
300명 설문 결과 엑셀 파일을 업로드하고 "부서별 만족도 평균을 계산해서 낮은 순서로 정렬해줘"라고 입력한다. Python 한 줄 몰라도 분석 결과를 얻는다.

*사례 2: 마케터*  
매주 경쟁사 5곳의 블로그 최신 포스트를 스캔해서 주요 키워드를 표로 정리하는 자동화를 설정해 두면, Codex가 월요일 아침마다 결과물을 만들어 둔다.

*사례 3: 콘텐츠 제작자*  
유튜브 스크립트 텍스트를 붙여넣고 "영어로 번역하고 .srt 자막 형식으로 변환해줘"라고 요청한다.

**Claude Code를 선택할 때 유리한 상황**

- 내 로컬 폴더와 파일을 직접 다뤄야 할 때
- 한 번에 대량의 문서를 읽고 정리해야 할 때
- 결과물의 정확도가 속도보다 중요할 때

*사례 1: 기획자*  
폴더 안에 흩어진 회의록 30개를 한꺼번에 읽고 "프로젝트별로 결정 사항만 추출해서 표로 만들어줘"라고 요청한다.

*사례 2: 교육자*  
PDF 강의 자료를 로컬에서 직접 읽어 "이 내용을 10문항 퀴즈로 만들되, 정답과 해설도 포함해줘"라고 지시한다.

## 6. 어떤 도구를 골라야 하는가

명확한 판단 기준을 정리한다.

**Codex를 선택한다**
- ChatGPT 이미 사용 중
- 비용 효율을 중시
- 여러 작업을 병렬로 처리하고 싶음
- 웹 UI로 간편하게 시작하고 싶음
- Microsoft 생태계 연동이 중요

**Claude Code를 선택한다**
- 코드 품질과 정확도를 최우선
- 내 로컬 파일을 직접 다뤄야 함
- 복잡한 대형 프로젝트의 전체 맥락 이해가 필요
- 세밀한 자동화 정책 제어가 필요

**둘 다 쓴다**
- 일상적인 반복 작업은 Codex (빠르고 저렴)
- 중요 결과물의 최종 검토는 Claude Code (정확도 우선)
- 실제로 두 도구를 혼용하는 개발자가 증가하는 추세다
