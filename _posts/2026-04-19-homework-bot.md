매일 저녁 "오늘 숙제 했어?" "학원 몇 시야?" "준비물 챙겼어?" 이 대화를 반복하고 있다면, AI 봇이 그 역할을 대신할 수 있다. 선생님이 과제를 올리면 봇이 아이에게 알려주고, 아이가 완료 체크를 하면 부모에게 보고가 간다. 코딩 없이도 가능하다.

두 가지 방법을 소개한다. ChatGPT 그룹챗을 활용하는 방법과 텔레그램 봇을 만드는 방법이다.

---

## 방법 1. ChatGPT 그룹챗 활용

### 어떤 방식인가

ChatGPT Plus 또는 Team 플랜에서는 여러 명이 같은 GPT를 공유하는 그룹 환경을 구성할 수 있다. 선생님과 학부모, 아이가 같은 공간에서 AI와 대화하며 스케줄을 관리한다.

### 준비물

ChatGPT Plus 계정(월 20달러) 또는 Team 플랜이 필요하다. 참여하는 모든 사람이 ChatGPT 계정을 가지고 있어야 한다.

### 셋팅 방법

**1단계 — 커스텀 GPT 만들기**

ChatGPT에 로그인한 후 왼쪽 메뉴에서 "My GPTs"를 클릭하고 "Create a GPT"를 선택한다.

Configure 탭에서 아래 내용을 입력한다.

이름 예시: "우리 반 숙제 도우미"

Instructions(시스템 프롬프트)에 아래 내용을 입력한다.

```
당신은 초등학생 학원 및 숙제 관리 도우미입니다.
역할:
- 선생님이 과제를 등록하면 날짜, 과목, 내용을 정리해서 저장합니다.
- 아이가 "완료"라고 입력하면 해당 과제를 완료 처리합니다.
- 부모가 "오늘 숙제 알려줘"라고 하면 미완료 과제 목록을 보여줍니다.
- 매일 저녁 7시에 그날 미완료 과제를 요약해서 알려줍니다.
- 학원 스케줄은 요일별로 정리해서 보관합니다.
말투: 아이에게는 친근하게, 부모와 선생님에게는 정중하게 답합니다.
```

**2단계 — 학원 스케줄 등록**

GPT를 만든 후 대화창에 아래처럼 입력해서 스케줄을 등록한다.

```
학원 스케줄 등록해줘.
월수금: 수학학원 오후 4시~6시
화목: 영어학원 오후 5시~7시
토요일: 피아노 오전 10시~11시
```

**3단계 — 과제 등록 (선생님 역할)**

선생님 또는 부모가 과제를 이렇게 등록한다.

```
과제 등록: 수학 p.45~47 연습문제, 마감 내일까지
과제 등록: 영어 단어 20개 외우기, 마감 이번 주 금요일
```

**4단계 — 아이가 완료 체크**

아이가 숙제를 마치면 직접 입력한다.

```
수학 숙제 완료
```

봇이 "수학 p.45~47 연습문제 완료 처리했어. 잘했어! 남은 숙제는 영어 단어 외우기야."라고 응답한다.

**5단계 — 부모 확인**

부모가 확인할 때는 이렇게 묻는다.

```
오늘 숙제 현황 알려줘
이번 주 학원 스케줄 알려줘
```

### ChatGPT 방식의 장단점

장점은 설정이 가장 간단하고, 한국어 이해도가 높으며, 별도 앱 설치가 필요 없다는 것이다. 단점은 자동 알림 발송이 어렵고, 모든 참여자가 ChatGPT 계정이 있어야 하며, 대화 내용이 분산될 수 있다는 것이다.

## 방법 2. 텔레그램 봇 만들기

### 어떤 방식인가

텔레그램 그룹채팅방에 AI 봇을 초대해서 운영한다. 선생님, 부모, 아이가 같은 채팅방에 있고 봇이 스케줄 관리와 알림을 자동으로 처리한다. 코딩 없이 n8n이라는 무료 자동화 툴을 사용한다.

### 준비물

텔레그램 앱(무료), n8n 계정(무료 플랜 있음, n8n.io), ChatGPT API 키(OpenAI 계정 필요)가 필요하다.

### 셋팅 방법

**1단계 — 텔레그램 봇 만들기**

텔레그램에서 @BotFather를 검색해서 대화를 시작한다.

```
/newbot
```

봇 이름을 입력한다. 예시: "우리반숙제봇"

봇 username을 입력한다. 예시: "ourclass_homework_bot"

완료되면 BotFather가 API 토큰을 준다. 이것을 복사해서 저장해둔다.

```
예시: 7234567890:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

**2단계 — 텔레그램 그룹방 만들기**

텔레그램에서 새 그룹을 만들고 선생님, 부모, 아이를 초대한다. 그룹명 예시: "윤슬이 학습 관리방"

그룹 설정에서 방금 만든 봇을 관리자로 추가한다. 봇 username을 검색해서 초대하고 관리자 권한을 준다.

**3단계 — n8n 자동화 설정**

n8n.io에 가입하고 새 워크플로우를 만든다.

첫 번째 노드: Telegram Trigger 추가

```
Bot Token: 1단계에서 받은 토큰 입력
Updates: message 선택
```

두 번째 노드: IF 조건 추가

텍스트에 "과제"가 포함되면 과제 등록 처리, "완료"가 포함되면 완료 처리, 그 외는 일반 대화로 분기한다.

세 번째 노드: OpenAI Chat Model 추가

```
API Key: OpenAI에서 발급받은 키 입력
Model: gpt-4o
System Message:
"당신은 초등학생 학습 관리 봇입니다.
과제 등록 시 날짜, 과목, 내용을 정리합니다.
완료 메시지 수신 시 해당 과제를 완료 처리합니다.
스케줄 조회 시 정리된 형태로 보여줍니다.
아이에게는 칭찬과 응원을 함께 전합니다."
```

네 번째 노드: Telegram Send Message 추가

AI가 생성한 응답을 채팅방으로 발송한다.

**4단계 — 자동 알림 설정**

저녁 알림을 위해 별도 워크플로우를 만든다.

Schedule Trigger 노드를 추가하고 매일 저녁 7시로 설정한다. OpenAI 노드에서 "오늘 미완료 과제 목록을 정리해서 부모님께 보고하는 메시지를 작성해줘"라는 프롬프트를 실행한다. Telegram Send Message로 그룹방에 발송한다.

**5단계 — 실제 사용 시나리오**

선생님이 채팅방에 입력한다.

```
@우리반숙제봇 과제등록: 수학 p.52 1~10번, 마감 내일
```

봇이 응답한다.

```
✅ 과제가 등록되었습니다.
과목: 수학
내용: p.52 1~10번
마감: 내일 (4월 18일)
```

아이가 완료 후 입력한다.

```
@우리반숙제봇 수학 완료
```

봇이 응답한다.

```
🎉 수학 숙제 완료! 정말 잘했어!
오늘 남은 숙제: 영어 단어 외우기
```

저녁 7시에 봇이 자동으로 부모에게 알린다.

```
📋 오늘의 학습 현황 보고
완료: 수학 p.52
미완료: 영어 단어 외우기 (마감 이번 주 금요일)
내일 학원: 영어학원 오후 5시
```

### 텔레그램 방식의 장단점

장점은 자동 알림이 가능하고, 별도 앱을 새로 배울 필요 없이 채팅방에서 모든 것이 처리되며, 선생님과 부모가 같은 공간에서 소통할 수 있다는 것이다. 단점은 초기 설정에 30분~1시간 정도 시간이 필요하고, 텔레그램을 처음 쓰는 경우 앱 설치 과정이 필요하다는 것이다.

---

## 두 방법 비교

| 항목 | ChatGPT 그룹챗 | 텔레그램 봇 |
|------|--------------|------------|
| 설정 난이도 | 쉬움 (10분) | 보통 (1시간) |
| 자동 알림 | 어려움 | 가능 |
| 비용 | ChatGPT Plus 월 20달러 | API 사용료 (소규모 무료 수준) |
| 한국어 | 매우 자연스러움 | 자연스러움 |
| 추천 대상 | 빠르게 시작하고 싶은 경우 | 자동화까지 원하는 경우 |

처음 시작한다면 ChatGPT 방식으로 1주일 써보고, 자동 알림이 필요하다고 느끼면 텔레그램 봇으로 전환하는 것을 추천한다.

아이의 숙제 관리에 AI를 도입했을 때 가장 큰 변화는 "엄마가 매일 확인하지 않아도 된다"는 것이다. 봇이 체크하고, 아이가 스스로 완료 처리하고, 부모는 저녁에 보고를 받는다. 이 구조가 자리 잡히면 아이도 스스로 관리하는 습관이 생긴다.
