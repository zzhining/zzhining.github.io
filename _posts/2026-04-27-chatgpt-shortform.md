인스타그램 릴스나 유튜브 쇼츠는 트렌드를 얼마나 빠르게 포착해서 알고리즘에 맞게 기획하느냐가 핵심이다. 매번 "요즘 뭐가 유행이지"를 서칭하고, 3초 훅을 짜느라 시간을 쓰는 루틴이 반복된다면 자동화를 고려할 때다.

ChatGPT에는 이 작업에 쓸 수 있는 기능이 두 가지 있다. 정해진 템플릿으로 대본 초안을 빠르게 뽑는 **GPTs**, 그리고 실시간 트렌드를 분석하고 씬별 이미지까지 생성해 완성형 파일로 만드는 **Agent**다. 두 방식 모두 ChatGPT **Plus 이상 유료 플랜**에서 사용할 수 있다. 같은 '숏폼 대본 기획' 작업을 두 방식으로 구현하는 방법을 단계별로 정리했다.

---

## 1. 두 방식의 차이

**GPTs**는 내가 설정한 Instructions(지침)를 기반으로 작동하는 맞춤형 챗봇이다. 한 번 세팅해두면 같은 구조의 대본 초안을 반복해서 빠르게 뽑을 수 있다. 말투, 출력 형식, 금지 표현까지 한 번 정의해두면 매번 같은 품질이 유지된다. 단, GPTs는 기본적으로 텍스트 출력 도구다. 트렌드 서칭은 Web Browsing 기능을 켜두면 일부 가능하지만, 실시간 트렌드를 분석하고 그에 맞게 대본 전체를 재구성하거나 파일을 생성하는 작업은 하지 못한다.

**Agent**는 동작 방식 자체가 다르다. 사용자가 '목표'를 던지면 에이전트가 스스로 단계를 나누고, 웹 서칭 → 대본 작성 → 이미지 생성 → 파일 빌드까지 하나의 흐름으로 실행한다. 중간에 개입하지 않아도 작업이 완수된다. GPTs가 정해진 레시피대로 요리한다면, Agent는 재료를 직접 사오고 요리하고 차려내는 과정 전체를 처리한다.

| | GPTs | Agent |
|---|---|---|
| **작동 방식** | 내가 설정한 규칙대로 텍스트 생성 | 목표를 받아 스스로 계획하고 실행 |
| **트렌드 반영** | 제한적 (Web Browsing 활성화 필요) | 실시간 웹 서칭으로 반영 |
| **이미지 생성** | DALL-E 기능 별도 활성화 시 가능 | 씬별 이미지 자동 생성·매칭 가능 |
| **결과물** | 화면 출력 텍스트 | 이미지 포함 완성형 .docx 파일 |
| **소요 시간** | 10~30초 | 5~15분 |
| **적합한 상황** | 반복적인 초안 생산 | 트렌드 기반 완성형 기획서 |

## 2. GPTs 세팅 방법

### 세팅 절차

ChatGPT 메인 화면에서 **[Explore GPTs] → [+ Create] → [Configure]** 탭을 클릭한다. 각 항목에 아래 값을 입력한다.

| 설정 항목 | 입력 내용 |
|---|---|
| **Name** | `숏폼 릴스 마스터 빌더` |
| **Description** | `주제만 던지면 훅-본문-CTA 구조의 60초 숏폼 대본을 짜주는 비서` |
| **Instructions** | 아래 프롬프트 복사 후 붙여넣기 |
| **Conversation starters** | `AI 부업을 주제로 릴스 대본 짜줘` / `퍼널 마케팅을 쉽게 설명하는 쇼츠 대본 짜줘` |
| **Capabilities** | `Web Browsing`, `Advanced Data Analysis` 활성화 |

**Instructions 프롬프트**

```
[Role]
너는 인스타그램 릴스와 유튜브 쇼츠 떡상 공식을 완벽히 꿰고 있는 스타 콘텐츠 디렉터다.

[Task]
사용자가 키워드나 단순 주제를 던지면, 시청 지속시간을 극대화하는 60초 숏폼 대본을 생성해야 한다.

[Output Format]
결과물은 무조건 다음 포맷으로만 출력할 것:
- [콘텐츠 컨셉]: 타겟과 핵심 셀링 포인트
- [추천 타이틀]: 호기심을 자극하는 카피라이팅 제목 3가지
- [0~3초 훅(Hook)]: 화면 연출 및 오디오 카피 (예시: "이거 모르면 평생 후회합니다")
- [3~50초 본문(Body)]: 속도감 있는 리듬의 스토리텔링 (자막/나레이션 구분)
- [50~60초 행동유도(CTA)]: "더 많은 정보는 [저장]하고 프로필을 확인하세요!"

[Tone & Manner]
문장은 10자 내외로 극도로 짧고 직관적일 것. 트렌디한 구어체 사용.
```

### GPTs의 장점

GPTs의 가장 큰 강점은 **일관성**이다. 동일한 구조와 말투를 계속 유지해야 하는 채널에서 특히 유용하다. 세팅이 한 번 끝나면 사이드바에 고정해두고 매일 꺼내 쓸 수 있다. 팀 계정을 쓰는 경우라면 만들어둔 GPTs를 팀원과 링크로 공유하는 것도 가능하다.

대화 시작 키워드(Conversation starters)를 미리 등록해두면 GPTs를 켤 때마다 자주 쓰는 요청이 버튼처럼 나타난다. 매번 같은 프롬프트를 입력할 필요 없이 클릭 한 번으로 시작할 수 있어 빠르다.

### GPTs의 한계와 주의사항

GPTs는 출력이 텍스트에 한정된다. DALL-E 이미지 생성 기능을 Capabilities에서 따로 켜두면 이미지도 생성할 수 있지만, 대본 씬과 이미지를 자동으로 매칭해서 파일로 묶는 작업은 하지 못한다. 이미지가 필요한 완성형 기획서를 만들려면 Agent를 써야 한다.

Web Browsing 기능을 켜두더라도 GPTs가 항상 최신 트렌드를 반영하는 것은 아니다. 지침(Instructions) 안에 "최신 트렌드를 반드시 검색해서 반영하라"는 명령을 포함해야 실제로 웹 서칭이 실행된다. 이 부분을 빠뜨리면 학습 데이터 기준으로만 대본을 작성하므로 트렌드가 반영되지 않는다.

> ⚠️ **GPTs는 작업을 기억하지 않는다**  
> GPTs는 대화 세션이 끝나면 내용을 기억하지 않는다. 지난 대화에서 만든 대본을 이어서 수정하려면 이전 결과를 복사해서 새 대화에 붙여넣어야 한다. 장기 프로젝트나 반복 수정이 많은 작업이라면 Projects 기능을 함께 활용하는 것이 낫다.

## 3. Agent 실전 프롬프트

### Agent가 실제로 하는 일

Agent는 ChatGPT가 내장한 가상 컴퓨터 환경에서 실행된다. 목표를 받으면 단계별 계획을 스스로 세우고, 실시간으로 웹을 탐색하거나 파이썬 코드를 실행하면서 작업을 완수한다. 사용자가 버튼을 누르거나 개입하지 않아도 여러 단계가 자동으로 연결된다.

이 글에서 소개하는 워크플로우는 다음과 같이 구성된다.

1. **웹 서칭** — 주제 관련 최신 트렌드 키워드와 카피라이팅 패턴 수집
2. **대본 작성** — 씬 단위로 구분된 60초 스크립트 생성
3. **이미지 생성** — 각 씬의 분위기에 맞는 배경 이미지를 DALL-E로 생성
4. **씬-이미지 매칭** — 대본 씬 번호와 이미지를 1:1로 연결
5. **파일 빌드** — 씬별로 이미지와 대본이 나란히 배치된 .docx 파일 생성
6. **검수 및 출력** — 누락 여부 확인 후 다운로드 링크 제공

실행은 간단하다. 아래 프롬프트를 채팅창에 붙여넣고 `[여기에 주제 입력]` 부분만 바꾸면 된다.

### Agent 프롬프트

```
/agent
[목표]: [여기에 주제 입력, 예시: 직장인 1인 법인 설립 노하우]를 주제로,
현재 SNS에서 가장 핫한 트렌드를 반영한 60초 숏폼 대본과
각 씬에 매칭된 이미지를 포함한 완성형 기획서 파일을 만들어줘.

[워크플로우]

1. [Web Browsing 실행]:
   주제와 관련해 최근 유튜브 쇼츠 및 인스타그램 릴스에서
   조회수가 높거나 댓글 반응이 뜨거운 키워드와 카피라이팅 패턴을
   직접 구글링해 트렌드 데이터를 수집해라.

2. [대본 작성]:
   수집된 트렌드를 기반으로 아래 씬 구조에 맞게 대본을 작성해라.
   각 씬은 화면 연출 지시문, 자막, 나레이션을 명확하게 구분해서 작성해라.
   - 씬 1 [0~3초 훅(Hook)]: 시청자를 멈추게 만드는 초강력 카피
   - 씬 2 [3~20초 본문 1단계]: 문제 제기 또는 공감 유도
   - 씬 3 [20~40초 본문 2단계]: 핵심 정보 전달
   - 씬 4 [40~50초 본문 3단계]: 구체적 팁 또는 해결책 제시
   - 씬 5 [50~60초 CTA]: 저장·팔로우·링크 클릭 유도

3. [이미지 생성]:
   대본의 각 씬(씬 1~씬 5)에 맞는 배경 이미지를 DALL-E로 생성해라.
   - 이미지는 세로형 숏폼 비율(9:16)을 고려한 구도로 만들어라.
   - 각 이미지의 분위기와 시각적 요소는 해당 씬의 핵심 메시지와 일치해야 한다.
     예시: 훅 씬이 "이거 모르면 후회"라면 → 긴장감 있는 클로즈업 구도
          본문 씬이 정보 전달이라면 → 깔끔한 인포그래픽 스타일
          CTA 씬이라면 → 행동을 유도하는 밝고 강조된 구도
   - 생성된 이미지 파일명은 씬 번호에 맞게 scene_01.png ~ scene_05.png로 저장해라.

4. [파일 빌드]:
   내부 파이썬 환경에서 python-docx 라이브러리로 .docx 파일을 빌드해라.
   - 파일 구성: 씬 번호 → 이미지 → 대본 스크립트 순서로 배치
   - 이미지와 대본이 한눈에 비교되도록 2열 표(Table) 구조를 사용해라.
   - 씬별 구분선을 삽입해서 인쇄했을 때도 가독성이 유지되도록 해라.

5. [검수 및 출력]:
   씬 번호와 이미지 매칭이 누락 없이 완성됐는지 스스로 검수한 뒤,
   즉시 다운로드할 수 있는 .docx 파일 링크를 제공해라.
```

### Agent 사용 시 알아둘 것

Agent는 실행 시간이 GPTs보다 오래 걸린다. 웹 서칭, 이미지 생성, 파일 빌드를 순서대로 처리하기 때문에 전체 작업에 5~15분 정도 걸린다. 실행 중에는 각 단계가 진행되는 상황이 화면에 실시간으로 표시된다.

이미지 생성 단계에서 씬별 분위기 설명이 구체적일수록 결과물 퀄리티가 달라진다. 프롬프트에서 씬별 예시 구도를 직접 지정해주는 이유가 여기에 있다. 원하는 스타일이 있다면 "미니멀 화이트 배경", "레트로 감성", "다크 배경에 강조 텍스트" 같은 스타일 키워드를 프롬프트에 추가하면 반영된다.

Agent가 생성한 .docx 파일의 이미지는 저작권 문제가 없는 AI 생성 이미지다. 다만 DALL-E가 만든 이미지가 실제 브랜드나 상표와 유사하게 나오는 경우가 있으니 상업용으로 사용하기 전에 확인이 필요하다.

> 💡 **완성된 파일이 곧바로 발행용이라고 생각하지 않는 것이 좋다**  
> Agent가 만든 기획서는 완성도 높은 초안이지, 검수가 완료된 최종본이 아니다. 대본의 문장이 브랜드 말투와 맞는지, 이미지 구도가 실제 촬영 방향과 맞는지는 사람이 확인해야 한다. AI는 기획의 속도를 높여주는 도구이고, 최종 방향성 결정은 콘텐츠 디렉터의 몫이다.

## 4. GPTs vs Agent 비교

| 항목 | GPTs | Agent |
|---|---|---|
| **개념** | 정해진 규칙에 따라 답하는 맞춤형 챗봇 | 목표를 받아 스스로 계획·실행하는 AI |
| **실행 방법** | Configure 메뉴에서 지침 사전 입력 후 대화 | 채팅창에 `/agent` + 목표 입력 |
| **트렌드 반영** | Web Browsing 켜두면 일부 가능 | 실시간 웹 서칭으로 반영 |
| **이미지 생성** | DALL-E 기능 별도 활성화 시 개별 생성 가능 | 씬별 이미지 자동 생성 및 대본과 매칭 |
| **결과물** | 화면에 출력되는 텍스트 | 씬-이미지 매칭 포함 완성형 .docx 파일 |
| **소요 시간** | 10~30초 | 5~15분 |
| **일관성** | 동일 구조 반복 유지 강점 | 매 실행마다 트렌드에 따라 결과 다름 |
| **팀 공유** | 링크로 공유 가능 | 공유 불가 (개인 실행) |
| **필요 플랜** | ChatGPT Plus 이상 | ChatGPT Plus 이상 |

> 💡 **어떤 방식을 선택할까**  
> 매일 같은 채널 톤으로 아이디어를 빠르게 뽑아야 한다면 GPTs를 사이드바에 등록해두고 쓴다. 지금 이 순간 가장 핫한 트렌드를 반영한 이미지 포함 완성형 기획서가 필요하다면 Agent에게 목표를 위임하는 것이 낫다. 둘을 섞어 쓰는 방법도 있다. GPTs로 초안을 빠르게 뽑은 뒤, 그 결과를 Agent에게 넘겨 이미지 생성과 파일 빌드만 맡기는 방식이다.
