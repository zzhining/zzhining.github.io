ChatGPT에 파일을 올려본 사람이라면 이 불편함을 알 것이다. 한 번에 파일 하나, 매번 새 대화, 어제 분석한 내용은 오늘 다시 설명해야 한다. **Claude Code**를 쓰면 다르다. "docs 폴더에 있는 회의록 파일 전부 읽고 결정 사항만 추출해줘"라고 한 번만 말하면 된다. AI가 내 컴퓨터 폴더를 직접 열어서 파일 20개를 차례로 읽고, 하나의 정리된 문서를 만들어준다.

이 글은 코딩을 전혀 모르는 직장인이 이 경험을 처음으로 해볼 수 있도록 설치부터 실습까지 순서대로 안내한다.

> - **개인 PC 또는 설치 권한이 있다** → 아래 가이드를 순서대로 따라 한다.

## 1. 이 가이드에서 만들 것

실습 시나리오는 다음과 같다.

> **상황:** `meeting_notes` 폴더 안에 회의록 `.txt` 파일이 20개 있다.  
> **목표:** 각 파일에서 결정 사항과 액션 아이템만 뽑아 날짜순으로 정리한 하나의 요약 문서를 만든다.  
> **소요 시간:** AI 실행 포함 약 5분

ChatGPT 기준으로 같은 작업을 하려면 파일 20개를 한 개씩 올리고, 매번 같은 요청을 반복하고, 결과를 직접 복사해서 합쳐야 한다. 최소 30분이 걸리는 작업이다.

## 2. 설치 없이 시작하기 — Codex 웹 버전

설치 과정이 부담스럽거나 회사 PC 제약이 있다면 **OpenAI Codex 웹 버전**으로 먼저 경험해볼 수 있다. 단, 웹 버전은 내 컴퓨터 폴더를 직접 읽지 못하고 **GitHub에 올린 파일**만 처리할 수 있다는 한계가 있다.

**웹 버전 시작 방법**

1. `chatgpt.com/codex`에 접속한다.
2. ChatGPT Plus 이상 계정으로 로그인한다.
3. GitHub 계정을 연결하고 처리할 파일이 담긴 레포를 선택한다.
4. 자연어로 지시를 입력하면 클라우드에서 작업이 실행된다.

**언제 웹 버전으로 충분한가**

- 파일이 이미 GitHub에 있는 경우
- 작업 결과를 Pull Request 형태로 받고 싶은 경우
- 일단 어떤 도구인지 체험해보고 싶은 경우

**언제 로컬 설치가 필요한가**

- 내 컴퓨터 폴더를 직접 다뤄야 하는 경우 (이 가이드의 주 시나리오)
- 회사 내부 문서라서 GitHub에 올리면 안 되는 경우
- 파일 저장까지 자동으로 처리해야 하는 경우

로컬 설치 가이드는 다음 섹션부터 이어진다.

## 3. 파일 형식별 처리 가능 범위 — 시작 전에 반드시 확인

Claude Code가 모든 파일을 똑같이 처리하는 것은 아니다. 파일 형식에 따라 처리 방식과 정확도가 달라진다. 실습 전에 내 파일이 어떤 형식인지 확인하고 아래 표를 참고한다.

| 파일 형식 | 처리 방식 | 권장도 | 비고 |
|---|---|---|---|
| `.txt` | 직접 읽기 | ⭐⭐⭐ 최적 | 가장 안정적 |
| `.md` | 직접 읽기 | ⭐⭐⭐ 최적 | 마크다운 구조 인식 |
| `.csv` | 직접 읽기 | ⭐⭐⭐ 최적 | 표 구조 인식 |
| `.json` | 직접 읽기 | ⭐⭐⭐ 최적 | 데이터 구조 인식 |
| `.docx` | 변환 후 읽기 | ⭐⭐ 조건부 | Word가 열려있으면 실패 가능 |
| `.xlsx` | 변환 후 읽기 | ⭐⭐ 조건부 | 복잡한 수식은 누락될 수 있음 |
| `.pdf` | 변환 후 읽기 | ⭐ 제한적 | 이미지 기반 PDF는 읽기 불가 |
| `.hwp` | 읽기 불가 | ✗ | 변환 필요 (아래 참고) |

**`.docx` 파일을 처리하려면**

Word 파일은 Claude Code가 직접 읽을 수는 있지만, 실행 중에 Word에서 해당 파일이 열려 있으면 잠금 오류가 발생한다. 안전하게 처리하려면 두 가지 방법이 있다.

방법 1 — Word를 닫은 상태에서 실행한다. (가장 간단)

방법 2 — 사전에 `.txt`로 변환한다. Word에서 파일 열기 → 다른 이름으로 저장 → 파일 형식을 "일반 텍스트(.txt)"로 선택한다.

**`.hwp` 파일을 처리하려면**

한글(HWP) 파일은 Claude Code가 직접 읽지 못한다. 한컴오피스에서 파일을 열고 "다른 이름으로 저장 → .txt 또는 .docx"로 변환한 뒤 처리한다.

이 가이드의 실습은 **`.txt` 파일 기준**으로 진행한다. `.txt`가 없다면 지금 메모장(윈도우) 또는 텍스트 편집기(맥)로 샘플 파일 2~3개를 만들어 두고 따라하는 것을 권장한다.

## 5. Node.js 설치

Claude Code 설치를 위한 사전 준비다. 한 번만 설치하면 이후에는 필요 없다.

**윈도우 사용자**

1. 브라우저에서 `https://nodejs.org`에 접속한다.
2. 초록색 **LTS** 버튼을 클릭해서 설치 파일을 다운로드한다.
3. 다운로드된 `.msi` 파일을 더블클릭하고 "Next"를 계속 눌러 설치를 완료한다.
4. **시작 메뉴 → Windows PowerShell**을 열고 다음을 입력한다.

```bash
node --version
```

`v22.0.0` 같은 숫자가 나오면 설치 성공이다.

**맥 사용자**

1. `https://nodejs.org`에 접속한다.
2. **LTS** 버튼을 클릭해서 `.pkg` 파일을 다운로드한다.
3. 설치 파일을 열고 진행한다.
4. **Launchpad → 기타 → 터미널**을 열고 입력한다.

```bash
node --version
```

숫자가 나오면 완료다.

> 🛠 **설치 중 오류가 나는 경우**  
> 윈도우에서 "권한이 없습니다" 오류가 뜨면, PowerShell을 **마우스 우클릭 → 관리자 권한으로 실행**한 뒤 다시 시도한다.

## 8. 실습: 회의록 폴더 일괄 처리

**Step 1. 폴더 위치 확인**

처리할 파일이 있는 폴더의 경로를 확인한다.

- 윈도우: 탐색기에서 폴더를 열고 상단 주소창을 클릭하면 경로가 표시된다. (예: `C:\Users\홍길동\Documents`)
- 맥: Finder에서 폴더를 선택하고 `Command + Option + P`를 누르면 경로창이 나타난다.

**Step 2. 터미널에서 폴더로 이동**

`cd`는 폴더 안으로 들어가는 명령어다. 회의록 폴더(`meeting_notes`)의 상위 폴더로 이동한다.

```bash
# 윈도우 예시
cd "C:\Users\홍길동\Documents"

# 맥 예시
cd /Users/honggildong/Documents
```

이동이 됐는지 확인하려면 다음을 입력한다.

```bash
# 윈도우
dir

# 맥
ls
```

`meeting_notes` 폴더 이름이 목록에 보이면 올바른 위치에 있는 것이다.

**Step 3. Claude Code 실행**

```bash
claude
```

다음과 같은 화면이 나오면 준비가 된 것이다.

```
Claude Code v1.x.x
> 
```

**Step 4. 지시 입력**

아래 프롬프트를 그대로 붙여넣는다. `meeting_notes`는 실제 폴더 이름으로 교체한다.

```
meeting_notes 폴더 안에 있는 모든 .txt 파일을 읽어줘.
각 파일에서 다음 두 가지를 추출해줘.
1. 결정 사항: 회의에서 최종적으로 결정된 내용
2. 액션 아이템: 누가 무엇을 언제까지 해야 하는지

모든 파일의 내용을 파일 이름 기준 날짜 순서로 정리해서
summary.md 파일로 저장해줘. 한국어로 작성해줘.
```

Enter를 누르면 Claude Code가 폴더를 스캔하기 시작한다.

**Step 5. 진행 과정 확인**

터미널 화면에 다음과 같은 메시지가 나타난다.

```
Reading files in meeting_notes/...
Found 20 files.
Reading 2026-04-01_기획팀회의.txt...
Reading 2026-04-08_팀장회의.txt...
...
Writing summary.md...
Done.
```

파일 수에 따라 30초에서 2분 정도 걸린다.

**Step 6. 결과 확인**

작업이 완료되면 현재 폴더에 `summary.md` 파일이 생성된다. 다음 명령어로 내용을 바로 확인할 수 있다.

```bash
# 윈도우
type summary.md

# 맥
cat summary.md
```

또는 탐색기/Finder에서 파일을 더블클릭해서 메모장이나 텍스트 편집기로 열면 된다.

## 9. 실전 프롬프트 모음

파일 형식별로 바로 쓸 수 있는 프롬프트다.

**`.txt` 회의록 → 주간 보고서**

```
reports 폴더 안의 모든 .txt 파일을 읽고
매출, 방문자 수, 이슈 사항을 추출해서
날짜 순서로 정리한 weekly_report.md를 만들어줘.
```

**`.csv` 고객 데이터 정제**

```
customer_data.csv 파일을 열어서 다음을 처리해줘.
1. 전화번호 컬럼을 010-0000-0000 형식으로 통일
2. 이메일이 비어있는 행에 unknown 입력
3. 이름이 중복된 행 제거 (첫 번째 행 유지)
수정된 파일은 customer_data_clean.csv로 저장해줘.
```

**`.txt` 설문 응답 분석**

```
survey_results.txt 파일을 읽고
긍정 응답과 부정 응답을 분리해줘.
각 카테고리에서 반복적으로 나오는 키워드 상위 5개를 뽑아서
survey_analysis.md로 저장해줘.
```

**폴더 내 파일 목록 정리**

```
project 폴더 안의 모든 파일 목록을 확인하고
파일 유형별(문서, 이미지, 스프레드시트)로 분류해서
파일 이름과 크기를 표로 정리한 file_list.md를 만들어줘.
```

## 10. 자주 하는 실수와 해결법

**"No such file or directory" 오류**

현재 위치가 잘못된 경우다. `pwd`(맥) 또는 `cd`(윈도우)를 입력해서 현재 위치를 확인하고, 회의록 폴더의 상위 폴더에 있는지 점검한다.

**파일을 읽지 못한다고 할 때 — `.docx` 한정**

Word에서 해당 파일이 열려있으면 잠금이 걸린다. Word를 완전히 닫은 뒤 다시 시도한다. 그래도 안 되면 파일을 `.txt`로 변환한다.

**한글이 깨져서 나올 때**

프롬프트에 다음 문장을 추가한다.

```
파일 인코딩은 UTF-8이야. 한국어로 출력해줘.
```

**이전 세션을 이어서 하고 싶을 때**

```bash
claude --resume
```

## 11. ChatGPT와 무엇이 다른가

| 상황 | ChatGPT | Claude Code |
|---|---|---|
| 파일 20개 처리 | 1개씩 업로드, 20번 반복 | 폴더 경로 한 번 지정 |
| 결과 저장 | 직접 복사해서 저장 | 파일로 자동 저장 |
| 다음날 이어서 작업 | 처음부터 다시 설명 | `--resume`으로 이어서 |
| 내 컴퓨터 폴더 접근 | 불가 | 직접 접근 |

핵심은 이것이다. ChatGPT는 내가 파일을 가져다 줘야 한다. Claude Code는 내 컴퓨터로 직접 가서 파일을 읽어온다.
