Claude를 도입한 조직에서 가장 많이 나오는 질문이 있다. "좋은 건 알겠는데, 어디서 어떻게 배워야 하나요?" 공식 문서를 찾아봐도 여기저기 흩어져 있어서 전체 그림을 잡기가 쉽지 않다.

Anthropic은 Claude 활용 교육을 위한 공식 과정을 Skilljar 플랫폼을 통해 제공하고 있다. 이 글에서는 5개 카테고리 전체 과정을 정리하고, 어떤 사람이 어떤 순서로 들으면 좋은지까지 담는다.

---

## 1. 전체 과정 한눈에 보기

| 카테고리 | 형태 | 주요 대상 |
|---|---|---|
| End-user Claude | 온라인 과정 + PDF | Claude를 처음 사용하는 모든 구성원 |
| Claude Code | 온라인 과정 2개 | 개발자, 자동화 업무 담당자 |
| Cowork | 온라인 과정 + 가이드 | 팀 협업 도구로 Claude를 활용하는 구성원 |
| Design | 영상 + 체험 | 신기능 얼리어답터 |
| Anthropic Academy | 통합 학습 허브 (알파) | Claude Code + Cowork 사용자 전체 |

모든 과정은 무료다. Skilljar 계정만 만들면 바로 수강할 수 있다.

## 2. End-user Claude - Claude를 처음 시작하는 사람을 위한 기초 과정

Claude를 업무에 처음 도입하는 조직이라면 여기서 시작한다. 기본 사용법과 프롬프트 작성 방법을 실습 위주로 다룬다. 개발자가 아닌 일반 직원 기준으로 설계되어 있어서 기술 배경 없이도 따라갈 수 있다.

**Claude 101**

기초 개념과 첫 사용법을 안내하는 온라인 과정이다. Claude를 한 번도 써본 적 없는 사람 기준으로 구성됐다.

[수강하기 →](https://anthropic.skilljar.com/claude-101)

**End User Guide (PDF)**

Claude 활용 전반을 문서로 정리한 자료다. 과정 수강 전후에 참고 자료로 활용하거나, 팀 내 배포용으로 사용하기 좋다.

[다운로드 →](https://cdn.sanity.io/files/4zrzovbb/website/97c4b90b0af9ad8b8332980010157044d58b40ba.pdf)

## 3. Claude Code - 개발과 자동화를 위한 실무 과정

코드 작성, 파일 처리 자동화, 반복 업무 제거를 목적으로 Claude Code를 활용하는 사람을 위한 과정이다. 개발자만을 위한 과정이 아니다. 반복적인 데이터 처리나 문서 작업이 많은 업무 담당자에게도 실질적으로 유용하다.

**Claude Code 101**

Claude Code의 기본 개념과 설치부터 시작하는 입문 과정이다. Claude Code를 처음 접하는 사람이라면 반드시 이 과정부터 시작한다.

[수강하기 →](https://anthropic.skilljar.com/claude-code-101)

**Claude Code in Action**

실제 업무에 Claude Code를 적용하는 심화 과정이다. 자동화 사례 중심으로 구성되어 있어서 101을 먼저 수강한 후 이어서 들으면 좋다.

[수강하기 →](https://anthropic.skilljar.com/claude-code-in-action)

Claude Code를 실제 프로젝트에 세팅하는 방법이 궁금하다면 → [CLAUDE.md 설정 가이드](/blog/2026/05/08/claude-md-guide/)

## 4. Cowork - 팀 협업 환경에서 Claude 활용하기

Claude를 개인 도구가 아닌 팀 단위 협업 플랫폼으로 사용하는 방법을 다룬다. 공유 프로젝트 관리, 팀 간 워크플로 연결 등 조직 차원의 활용을 고려하는 사람에게 적합하다.

**Intro to Claude Cowork**

Cowork의 개념과 주요 기능을 소개하는 입문 과정이다. Cowork가 무엇인지, 팀에서 어떻게 사용하는지 전체 그림을 잡는 데 좋다.

[수강하기 →](https://anthropic.skilljar.com/introduction-to-claude-cowork)

**Get Started with Cowork**

실제 Cowork를 설정하고 시작하는 방법을 단계별로 안내하는 가이드다. 입문 과정을 마친 후 실제 세팅 단계에서 참고한다.

[가이드 보기 →](https://support.claude.com/en/articles/13345190-get-started-with-cowork)

Anthropic Academy는 현재 알파 단계로 공개된 통합 학습 공간이다. Claude Code와 Cowork 사용자를 위한 시작 가이드, 부서별 활용 사례, 커넥터 설정 방법을 한 곳에서 확인할 수 있다.

개별 과정이 산발적으로 흩어져 있는 것과 달리, 조직 내 Claude 도입을 체계적으로 준비하는 담당자에게 유용한 공간이다.

| 제공 항목 | 내용 |

| 시작 가이드 | Claude Code / Cowork 처음 사용 안내 |
