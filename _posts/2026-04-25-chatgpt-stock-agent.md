사업보고서를 열어두고 밤을 새운 적이 있다. 삼성전자 사업보고서 PDF는 300페이지가 넘는다. 읽어야 할 것은 알겠는데, 어디서부터 시작해야 할지 막막했다. 중요한 숫자는 대체 어느 페이지에 있는지, 경쟁사인 SK하이닉스와 비교하려면 또 다른 파일을 뒤져야 했다. 현대차 IR 자료까지 더하면 그날 저녁은 이미 끝난 셈이었다.

지금은 다르다. ChatGPT에 파일을 올리고 질문 하나를 던지면 30분이 걸리던 작업이 5분 안에 끝난다. 처음에는 반신반의했다. 그런데 막상 써보니, 제대로 세팅한 ChatGPT는 개인 투자자에게 진짜 쓸 만한 리서치 도구가 된다.

이 글은 ChatGPT의 네 가지 기능인 Projects, Custom GPT, Canvas, Actions를 조합해 한국 주식 리서치 시스템을 만드는 방법을 정리한 것이다. 삼성전자, SK하이닉스, 현대차를 예시로 삼아 실제로 쓸 수 있는 프롬프트까지 담았다.

---

## 1. ChatGPT 주식 분석이 달라지는 이유

AI를 쓴다고 해서 분석의 판단 자체를 AI에게 맡기는 것이 아니다. 핵심은 속도다. 방대한 문서에서 내가 필요한 정보를 빠르게 뽑아내고, 비교하고, 구조화하는 작업을 AI가 대신한다. 그 시간을 아껴서 정작 중요한 판단, 즉 이 회사에 투자할 것인가 말 것인가에 집중할 수 있다.

ChatGPT가 주식 투자자에게 유용한 이유는 세 가지다. 긴 문서를 한 번에 읽고 핵심을 뽑아준다. 코딩 없이 계산기와 대시보드를 즉석에서 만들어준다. 그리고 같은 분석을 반복할 때 자동화가 가능하다.

> ⚠️ **ChatGPT는 완벽하지 않다**  
> 숫자를 틀리게 인용하거나 존재하지 않는 내용을 지어낼 때가 있다. 이 가이드에서는 그런 오류를 줄이는 세팅 방법에 특히 집중한다. AI를 100% 믿는 것이 아니라, 정확하게 작동하도록 환경을 만들어주는 것이 핵심이다.

## 2. Projects와 Custom GPT로 종목 전담 애널리스트 만들기

ChatGPT의 Projects 기능은 특정 종목에 대한 대화 맥락을 유지하고 문서를 저장해두는 공간이다. 매번 "삼성전자 투자자야, 이런 방식으로 분석해줘"라고 처음부터 설명하지 않아도 된다. 한 번 설정해두면 그 이후 모든 대화에 자동으로 적용된다.

ChatGPT 왼쪽 사이드바에서 Projects를 클릭하고 새 프로젝트를 생성한다. 삼성전자 리서치, SK하이닉스 분석, 현대차 IR 분석처럼 종목별로 만든다.

프로젝트를 만들었다면 지침을 설정한다. 이것이 진짜 핵심이다. 아래 템플릿을 그대로 복사해서 붙여넣으면 된다.

```
# 역할
너는 한국 주식 리서치 애널리스트야.
나는 한국 주식에 장기 투자하는 개인 투자자야.
너의 목표는 내가 투자 판단을 스스로 내릴 수 있도록
객관적이고 근거 기반의 분석 재료를 제공하는 거야.

# 근거 기반 답변 규칙
- 이 프로젝트에 업로드된 문서(사업보고서, 분기보고서, 컨퍼런스콜 스크립트, IR 자료)만을 근거로 답변해.
- 업로드된 문서에 없는 내용은 반드시 "해당 자료에서 확인할 수 없습니다"라고 답하고,
  절대로 외부 정보나 추측으로 채우지 마.
- 재무 수치, 경영진 발언, 가이던스 등은 반드시 출처를 [문서명, 페이지] 형식으로 표시해.

# 출력 형식
- 답변 맨 앞에 핵심 요약을 3줄 이내로 제시한다.
- 재무 및 수치 데이터는 Markdown 테이블로 정리한다.
- 리스크 요인은 별도 섹션으로 분리한다.
- 답변 마지막에 추가로 확인하면 좋은 질문 3가지를 제안한다.

# 어조 및 스타일
- 한국어로 답변하되, 회계 용어와 재무 지표(영업이익률, CapEx, FCF 등)는 영문을 병기한다.
- 확실한 것과 해석이 필요한 것을 구분해서 표현한다.
  예시: "사업보고서에 따르면 X이다" vs "이는 Y로 해석될 여지가 있다"
- 불필요한 서론 없이 핵심으로 바로 들어간다.

# 절대 하지 말아야 할 것
- 매수/매도/보유 추천 금지
- 목표 주가 제시 금지
- 단기 주가 방향 예측 금지
- 업로드된 문서 외 외부 정보(뉴스, 증권사 리포트, SNS 등) 사용 금지
- "일반적으로", "알려진 바에 따르면" 같은 출처 불명 표현 사용 금지
```

이 지침을 넣은 뒤 사업보고서나 컨퍼런스콜 스크립트를 업로드하면, ChatGPT가 그 문서만을 근거로 답변한다. 환각(hallucination)이 대폭 줄어든다.

보다 정교한 자동화가 필요하다면 Custom GPT를 활용한다. ChatGPT 메인 화면에서 Explore GPTs → Create를 선택한다. GPT Builder의 Instructions에 위 지침을 붙여넣고, Knowledge 섹션에 자주 쓰는 공시 자료를 올려두면 된다. Custom GPT는 Projects보다 지침 설정이 더 정교하고, 외부 API와 연결하는 Actions 기능도 사용할 수 있다.

## 3. 실전 프롬프트 — 컨퍼런스콜과 사업보고서 분석

프로젝트에 삼성전자 사업보고서와 컨퍼런스콜 스크립트를 업로드한 뒤, 아래 프롬프트를 사용한다.

**컨퍼런스콜 가이던스 변경 추적**

> 경영진이 컨퍼런스콜에서 언급한 향후 가이던스 변경 사항을 전 분기와 비교해서 표로 만들어줘. 이번 분기 가이던스, 전 분기 가이던스, 변화 방향, 경영진 코멘트 원문과 요약까지 포함해줘.

이 질문 하나로 손으로 하면 1시간 걸릴 작업이 3분 안에 끝난다. 가이던스 변화는 주가 흐름에 직결되는 정보다. 삼성전자가 HBM 매출 가이던스를 올렸는지 내렸는지, 현대차가 EV 판매 목표를 어떻게 조정했는지를 한눈에 볼 수 있다.

**사업보고서 리스크 매핑**

> 이 회사의 사업보고서에 나온 사업 위험 요인 중에서 실제로 실적에 영향을 줄 가능성이 높은 상위 5개를 뽑고, 컨퍼런스콜에서 경영진이 해당 리스크에 대해 뭐라고 대응했는지 연결해서 정리해줘.

사업보고서의 위험 요인 섹션과 컨퍼런스콜 발언을 교차 검증하는 것으로, 기관 애널리스트가 실제로 하는 작업이다. SK하이닉스의 메모리 업황 리스크를 경영진이 어떻게 보고 있는지, 현대차의 환율 리스크 언급이 이번 분기에 어떻게 달라졌는지 확인하는 데 특히 유용하다.

## 4. Canvas로 코딩 없이 투자 계산기 만들기

Canvas는 ChatGPT가 텍스트 답변을 넘어서 계산기, 대시보드, 인터랙티브 시각화를 실시간으로 만들어주는 기능이다. 코딩 없이 말로만 설명하면 결과물이 만들어진다.

ChatGPT 채팅창에서 아래 프롬프트를 입력하면 Canvas 모드가 자동으로 실행된다.

**복리 계산기**

> 한국 주식 투자자를 위한 복리 계산기를 만들고 싶어. 내가 원하는 은퇴 목표 금액에 도달하려면 현재 나이와 은퇴 시점까지 매월 얼마를 투자해야 하는지 다이나믹하게 바꿔서 확인할 수 있는 대시보드를 만들어줘. 투자 수익률과 인플레이션 가정도 바꿀 수 있어야 해. 금액 단위는 원화(KRW)로 표시해줘.


**밸류에이션 대시보드**

> 삼성전자, SK하이닉스, 현대차 중 하나의 티커를 입력하면 PER, PBR, EV/EBITDA, P/S 등 주요 밸류에이션 지표를 역사적 평균과 비교해서 현재 수준을 시각화할 수 있는 대시보드를 만들어줘. 더 필요한 정보 있으면 물어봐.

> 💡 **실시간 데이터는 자동으로 들어오지 않는다**  
> Canvas로 만든 밸류에이션 대시보드는 실시간 주가 데이터를 자동으로 가져오지 않는다. 직접 수치를 입력하거나, Code Interpreter를 통해 데이터를 불러오는 방식이 필요하다.

## 5. 공시자료 파일 분석하기

ChatGPT는 로컬 파일 시스템에 직접 접근하지 못한다. 공시자료 수집과 분석은 파일을 수동으로 업로드하는 방식으로 진행한다.

[DART](https://dart.fss.or.kr/)(금융감독원 전자공시시스템)에서 삼성전자, SK하이닉스, 현대차의 사업보고서와 분기보고서를 다운로드한 뒤 ChatGPT에 직접 첨부한다. PDF 파일을 그대로 올리면 된다.

파일을 올린 뒤 Code Interpreter(데이터 분석 기능)를 켜면 더 강력한 분석이 가능하다.

**재무 데이터 시각화**

> 업로드한 삼성전자 사업보고서에서 최근 5개 연도의 매출액, 영업이익, 영업이익률(Operating Margin)을 추출해서 연도별로 비교하는 차트를 만들어줘. 숫자는 조 원 단위로 정리해줘.

**경쟁사 비교**

> 업로드한 두 파일(SK하이닉스 사업보고서, 삼성전자 반도체 부문)에서 매출액, 영업이익, R&D 투자 비율을 각각 추출해서 두 회사를 나란히 비교하는 테이블을 만들어줘. 출처는 [문서명, 페이지] 형식으로 반드시 표시해줘.

DART Open API에서 무료로 API 키를 발급받으면, Custom GPT Actions와 연결해서 종목 코드를 입력하는 것만으로 최신 공시자료 목록을 불러올 수 있다.

## 6. Custom GPT Actions로 반복 분석 자동화하기

Actions는 Custom GPT에 외부 API를 연결해서 자동화된 워크플로우를 만드는 기능이다. DART Open API를 Actions에 연결하면 "삼성전자 최근 분기보고서 가져와줘" 한 마디로 최신 공시 목록을 불러올 수 있다. Custom GPT 만들기 화면에서 Actions를 클릭하고, DART API 스펙을 입력하면 된다.

아래 Instructions를 Custom GPT에 넣어두면, 다음번에 현대차 컨퍼런스콜 분석이 필요할 때 "현대차 컨퍼런스콜 분석해줘"라고 입력하고 파일만 올리면 전체 분석이 자동으로 진행된다.

```
# 역할
너는 한국 주식 어닝 분석 전문 애널리스트야.

# 트리거
사용자가 "[종목명] 컨퍼런스콜 분석해줘"라고 입력하면
아래 워크플로우를 자동으로 실행해.

# 워크플로우
1. 사용자가 입력한 종목의 최근 컨퍼런스콜 스크립트를 요청한다.
2. 업로드된 파일에서 아래 항목을 추출한다.
   - 이번 분기 주요 가이던스
   - 전 분기 대비 변경된 가이던스
   - 경영진 발언 중 톤이 변화한 부분
   - 리스크 섹션 업데이트 사항
3. 각 항목을 아래 형식으로 정리한다.
   - 핵심 요약 3줄
   - 가이던스 변화 테이블 (이전/현재/변화 방향/경영진 코멘트)
   - 경영진 톤 변화 분석
   - 리스크 업데이트
   - 다음 분기 모니터링 체크리스트

# 출력 규칙
- 모든 수치는 출처를 [문서명, 페이지] 형식으로 표시한다.
- 해석이 필요한 부분은 "이는 ~로 해석될 여지가 있다"로 구분한다.
- 매수/매도/목표 주가 언급 금지.
```
