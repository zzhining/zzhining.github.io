ChatGPT는 몇 달에 한 번씩 새로운 기능을 출시한다. Deep Research, Canvas, Agent Mode, 최근에는 Codex까지. 뉴스 헤드라인을 볼 때마다 '이런 것도 되는구나' 싶지만, 막상 내 화면을 보면 오늘도 프롬프트 창에 질문 한 줄을 입력하고 있다.

기능이 많아질수록 무엇부터 써야 할지 오히려 막막해진다. 이 글에서는 ChatGPT의 핵심 기능을 처음 시작하는 사람 기준으로 정리한다. 모델 선택부터 프롬프트 작성법, 초급·중급·고급 도구까지 — 채팅 한 줄에서 벗어나는 출발점으로 쓰기 좋다.

## 1. 처음 시작하는 3단계

**1단계 — [chatgpt.com](https://chatgpt.com/)에 접속한다**

브라우저, 데스크톱, 모바일에서 모두 이용할 수 있다.

**2단계 — 유료 계정으로 로그인되어 있는지 확인한다**

왼쪽 하단 프로필 아이콘에서 현재 플랜을 확인한다. Free 계정이라면 이 글에서 다루는 일부 모델과 도구를 사용할 수 없다.

**3단계 — 첫 메시지를 보낸다**

처음이라면 내 업무와 목적을 먼저 설명하고 시작하는 것이 좋다.

> 저는 [회사명]의 [직무] 담당자입니다. 주로 [주요 업무]를 담당하고 있어요.

또는 다음과 같이 나에 대해서 질문을 해달라고 요청하여 나에 대한 정보를 알려주는 방법도 있다.

> 당신은 앞으로 저와 함께 일하기 위해서 저에 대한 이해가 필요합니다. 저를 이해하기 위해 20가지 질문을 생성해서 물어보세요.

## 2. 프롬프트 작성 기본 공식

ChatGPT에서 원하는 결과를 얻으려면 **작업 + 맥락 + 기대 결과** 세 가지를 함께 담는 것이 기본이다.

**작업**
- 이 [회의 녹취록]을 정리해줘
- 이 [경쟁사 블로그 글]을 분석해줘
- 이 [고객 불만 데이터]에서 패턴을 찾아줘

**맥락**
- 결정 사항과 액션 아이템 중심으로
- 우리 마케팅팀 관점에서
- CS팀 팀장 보고용으로

**기대 결과**
- 담당자와 기한 포함해서 표 형식으로
- 시사점 3가지를 불릿으로
- 빈도 순 표 형식으로

**ChatGPT로 프롬프트 자체를 개선하기**

작성한 프롬프트가 마음에 들지 않을 때 ChatGPT에게 직접 개선을 요청할 수 있다.

- 이 프롬프트를 더 명확하고 구체적으로 개선해줘.
- Deep Research에 맞게 더 강력한 버전으로 바꿔줘.
- [특정 직무·산업군·상황]에 맞게 다시 작성해줘.

> 💡 **빈 화면이 막막할 때**  
> 먼저 음성이나 채팅으로 하고 싶은 말을 자유롭게 말한 뒤, "이 내용을 프롬프트로 정리해줘"라고 요청하면 된다. 처음부터 완벽한 프롬프트를 쓰려는 부담을 내려놓는 것이 가장 빠른 시작 방법이다.

## 3. 어떤 모델을 써야 하나

모델마다 처리 방식과 적합한 작업이 다르다. 무조건 최상위 모델을 쓰는 것이 정답이 아니다.

| 모델 | 설명 | 적합한 작업 |
|---|---|---|
| **Auto** | 프롬프트에 맞는 추론 수준을 자동으로 선택한다 | 일반 작업 기본값 |
| **Instant** | 일상적인 질문에 빠르게 응답한다 | 문장 다듬기, 요약, 브레인스토밍 |
| **Thinking** | 복잡한 작업을 위한 심층 추론에 적합하다 | 전문 지식 기반 업무, 긴 문서 작업, 심층 리서치 |
| **Pro** | 가장 높은 수준의 정밀성이 필요한 최상위 추론 모델이다 | 임원 보고용 분석, 복잡한 문제, 높은 정확성이 요구되는 작업 |

> 💡 **모델 선택이 헷갈린다면**  
> Auto로 시작한다. 모델 선택 메뉴에서 **Configure** → **"Auto-switch to thinking"**을 켜두면 단순한 작업은 Instant로, 복잡한 작업은 자동으로 Thinking 모드로 전환된다.

## 4. 도구와 기능 한눈에 보기

ChatGPT에는 채팅 외에 다양한 도구가 내장되어 있다. 설정 없이 바로 쓸 수 있는 초급 도구부터, 업무 흐름을 바꾸는 중급, 자동화와 팀 단위 활용을 위한 고급 도구까지 단계별로 나뉜다.

| 구분 | 도구 | 한 줄 설명 |
|---|---|---|
| **초급** | Search | 실시간 웹 검색으로 최신 정보를 가져온다 |
| **초급** | Data Analysis | 업로드한 파일을 분석하고 차트와 표를 만든다 |
| **초급** | Voice Mode | 음성으로 대화하고 지시한다 |
| **중급** | Canvas | 문서·코드를 대화와 분리된 편집 공간에서 작성하고 수정한다 |
| **중급** | ImageGen | 텍스트 설명을 기반으로 이미지를 생성한다 |
| **중급** | Memory | 내 정보와 맥락을 기억해 개인화된 응답을 제공한다 |
| **중급** | Projects | 주제별로 대화와 파일을 묶어 맥락을 이어간다 |
| **고급** | Deep Research | 여러 소스를 탐색해 구조화된 보고서를 만든다 |
| **고급** | Agent Mode | 여러 단계 작업을 계획하고 자율적으로 수행한다 |
| **고급** | Apps | Slack, Notion, Google Drive 등 사내 도구와 연결한다 |
| **고급** | Custom GPTs | 특정 업무에 최적화된 맞춤형 챗봇을 만든다 |
| **고급** | Skills | 팀이 만든 모범 프롬프트와 워크플로를 공유한다 |

## 5. 초급 도구 — 오늘부터 바로 쓰는 기능

별도 설정 없이 대화 창에서 바로 활성화할 수 있는 도구들이다. ChatGPT를 처음 쓴다면 여기서 시작한다.

**Search — 실시간 웹 검색**

ChatGPT의 학습 데이터는 특정 시점까지만 반영된다. Search는 이 한계를 보완한다. 오늘 날짜 기준의 정보나 최근 발표된 내용이 필요할 때 자동 또는 수동으로 활성화할 수 있다.

![Search 화면](/assets/image/chatgpt-04-24/image.png)

적합한 상황:
- "오늘 원/달러 환율 알려줘"처럼 실시간 수치가 필요할 때
- 최근 발표된 경쟁사 신제품이나 업계 뉴스를 확인할 때
- 특정 인물이나 기업의 최근 동향을 조사할 때

예시 프롬프트:

> 국내 생성형 AI 도입 현황에 대한 최근 기사나 보고서를 찾아서 핵심 내용을 3가지로 요약해줘.

---

**Data Analysis — 파일 업로드 분석**

엑셀, CSV 파일을 업로드하면 수식 없이 자연어로 데이터를 다룰 수 있다. 피벗 테이블이나 차트가 필요하지만 엑셀 함수에 익숙하지 않은 경우에 특히 유용하다. 분석 결과는 이미지나 파일로 내려받을 수 있다.

적합한 상황:
- 채널별 매출을 비교하거나 항목별 비중을 차트로 시각화할 때
- 고객 데이터에서 패턴이나 이상값을 찾아야 할 때
- 여러 시트에 흩어진 데이터를 하나의 요약표로 합칠 때

예시 프롬프트:

> 첨부한 파일은 지난 분기 채널별 매출 데이터야. 채널별 매출 비중을 파이차트로 만들고, 전월 대비 증감률도 함께 표로 정리해줘.

---

**Voice Mode — 음성 대화**

텍스트 입력 없이 말로 ChatGPT와 대화할 수 있다. 모바일 앱에서 특히 유용하고, 이동 중이거나 손이 자유롭지 않은 상황에서 사용하기 좋다. 실시간으로 주고받는 대화형 응답을 지원한다.

적합한 상황:
- 이동 중에 아이디어를 정리하거나 메모할 때
- 보고서 초안을 구어체로 불러준 뒤 텍스트로 정제할 때
- 언어 학습이나 발음 교정 연습을 할 때

## 6. 중급 도구 — 업무 흐름을 바꾸는 기능

기본 채팅에서 한 단계 나아가, 반복 작업을 줄이고 결과물의 품질을 높이는 도구들이다. 처음 쓸 때 설정이 약간 필요하거나 사용 패턴을 익히는 데 시간이 걸리지만, 한번 익히면 업무 방식 자체가 달라진다.

**Canvas — 문서 편집 공간**

일반 채팅에서는 결과물이 대화 흐름 안에 묻힌다. Canvas는 ChatGPT와의 대화 창 옆에 별도 편집 공간을 열어, 문서나 코드를 실시간으로 수정하고 다듬을 수 있게 한다.

![Canvas 화면](/assets/image/chatgpt-04-24/image-2.png)

적합한 상황:
- 보고서, 제안서, 블로그 글처럼 길게 작성하고 반복적으로 수정하는 문서
- "3단락을 2단락으로 줄여줘", "이 문장 톤을 더 부드럽게 바꿔줘"처럼 부분 수정이 잦은 작업
- 코드를 작성하며 실행 결과를 바로 확인해야 할 때

예시 프롬프트:

> 아래 회의 내용을 바탕으로 고객사에 보낼 제안서 초안을 Canvas에서 작성해줘. 구성: 배경 → 제안 내용 → 기대 효과 → 다음 단계  
> [회의 내용 붙여넣기]

---

**ImageGen — 이미지 생성**

텍스트로 원하는 이미지를 묘사하면 그에 맞는 이미지를 만들어준다. 스톡 이미지가 맞지 않거나, 특정 분위기와 구성의 시각 자료가 필요할 때 사용한다.

![ImageGen 예시](/assets/image/chatgpt-04-24/image-3.png)

적합한 상황:
- 발표 자료 표지나 섹션 구분 이미지가 필요할 때
- 브랜드 분위기에 맞는 소셜 미디어 이미지를 만들 때
- 아이디어를 시각화한 개념도나 일러스트가 필요할 때

예시 프롬프트:

> AI 기술 트렌드를 주제로 한 발표 자료 표지 이미지를 만들어줘. 파란 계열, 미니멀한 스타일, 데이터가 연결되는 느낌으로.

---

**Memory — 개인화 기억**

ChatGPT는 기본적으로 세션이 끝나면 대화 내용을 잊는다. Memory는 내가 알려준 정보를 세션을 넘어 기억하도록 한다. 직업, 팀, 자주 쓰는 용어, 선호하는 응답 방식 등을 저장해두면 매번 설명하지 않아도 된다.

![Memory 설정 화면](/assets/image/chatgpt-04-24/image-6.png)

적합한 상황:
- 직무와 회사 정보를 매번 설명하는 것이 번거로울 때
- 특정 형식이나 톤으로 항상 답변을 받고 싶을 때
- 진행 중인 프로젝트의 배경을 이어서 활용해야 할 때

Memory에 저장할 내용 예시:

> 나는 [회사명]의 HR 담당자야. 회사 규모는 200명이고, 채용과 온보딩을 주로 담당해. 답변은 항상 한국어로, 간결하게 핵심만 써줘.

---

**Projects — 주제별 대화 관리**

같은 주제의 대화와 파일을 하나의 프로젝트로 묶어 관리한다. 프로젝트 안에서 이어지는 대화는 이전 내용을 자동으로 참고한다. 하나의 주제를 여러 세션에 나눠 진행하거나, 팀원과 공유해야 하는 작업에 적합하다.



적합한 상황:
- 경쟁사 분석처럼 여러 번에 나눠 진행하는 리서치 작업
- 고객사별로 대화와 파일을 분리해서 관리할 때
- 팀원과 같은 맥락에서 ChatGPT를 함께 활용할 때

## 7. 고급 도구 — 자동화와 팀 확장

단순 응답을 넘어, ChatGPT가 스스로 계획하고 실행하거나 팀 단위로 활용할 수 있게 만드는 도구들이다. 초기 설정이나 팀 내 조율이 필요하지만, 반복 업무의 상당 부분을 줄일 수 있다.

**Deep Research — 심층 리서치 보고서**

여러 웹 소스를 직접 탐색하고 종합해 구조화된 보고서를 자동으로 만든다. 단순 검색과 달리, 여러 소스를 교차 검토하고 출처를 명시한 장문의 보고서를 생성한다. 작업 시간은 수 분에서 최대 30분까지 걸릴 수 있다.

적합한 상황:
- 시장 진입 전 경쟁사 분석이나 업계 트렌드 파악이 필요할 때
- 의사결정에 필요한 배경 조사를 빠르게 완료해야 할 때
- 여러 소스를 직접 찾아 읽기 어려운 복잡한 주제를 다룰 때

![Search 결과 예시](/assets/image/chatgpt-04-24/image-1.png)


예시 프롬프트:

> 국내 HR SaaS 시장에서 [우리 서비스]와 경쟁 중인 상위 5개 서비스를 조사하고, 각각의 가격 정책·주요 고객층·차별화 포인트를 비교한 보고서를 작성해줘.

다른 AI 도구로 리서치를 고도화하는 방법이 궁금하다면 → [Gemini + NotebookLM으로 리서치 고도화하기](/blog/2026/04/26/gemini-notebooklm-research/)

**Agent Mode — 다단계 자율 작업**

ChatGPT가 목표를 받으면 스스로 단계를 나누고, 검색·파일 접근·계산 등을 순서대로 실행한다. 중간에 직접 개입하지 않아도 여러 단계가 연결된 작업을 처음부터 끝까지 처리한다.

![Agent Mode 화면](/assets/image/chatgpt-04-24/image-4.png)

적합한 상황:
- "조사 → 정리 → 파일 저장"처럼 여러 단계가 연결된 작업
- 정해진 형식의 보고서나 데이터를 주기적으로 만들어야 할 때
- 여러 소스에서 정보를 수집해 하나로 합쳐야 할 때

예시 프롬프트:

> 국내 AI 스타트업의 최근 6개월 투자 현황을 조사하고, 투자사·피투자사·투자 금액·시리즈 단계를 정리한 표를 만들어 파일로 저장해줘.

> ⚠️ **Agent Mode 사용 전 확인할 것**  
> Agent Mode는 파일 시스템 접근, 외부 서비스 연동 등 실제 동작을 수행한다. 처음 사용 시 단계별로 진행 상황을 확인하면서 범위를 조금씩 넓혀가는 것이 좋다.

**Apps — 사내 도구 연결**

Slack, Notion, Google Drive, GitHub 등 사내에서 이미 사용하는 도구를 ChatGPT와 직접 연결한다. 연결 후에는 "지난주 Slack에서 논의한 내용을 요약해줘"처럼 도구를 넘나드는 작업이 가능하다.

![Apps 연결 화면](/assets/image/chatgpt-04-24/image-5.png)

적합한 상황:
- Slack 채널의 주요 논의 내용을 자동으로 요약할 때
- Google Drive 문서를 불러와 분석하거나 수정할 때
- 여러 도구에 흩어진 정보를 하나로 모아야 할 때

> ⚠️ **초기 연결 설정 필요**  
> 사내 도구 연동은 IT 담당자와 함께 초기 설정을 진행하는 경우가 많다. 개인 계정과 조직 계정의 권한 범위를 사전에 확인한다.

**Custom GPTs — 맞춤형 챗봇 제작**

특정 업무에 최적화된 전용 챗봇을 직접 만들 수 있다. 역할, 말투, 지식 범위, 금지 행동을 미리 설정해두면 매번 같은 프롬프트를 반복하지 않아도 된다.

![GPTs 화면](/assets/image/chatgpt-04-24/image-7.png)

적합한 상황:

- 팀원 누구나 같은 품질로 결과물을 만들어야 할 때
- 신입 교육용 Q&A봇이나 내규 안내봇이 필요할 때
