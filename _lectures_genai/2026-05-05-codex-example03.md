매주 월요일 아침 9시, 어김없이 같은 일을 한다. 지난 주 업무 로그 폴더를 열고, 파일을 하나씩 훑고, 완료된 항목을 추려서 보고서 양식에 옮긴다. 30분짜리 작업이지만 손이 가는 건 손이 가는 것이다.

**Claude Code 자동화(Automations)**는 이 흐름을 끊는다. 한 번 설정해 두면 매주 월요일 아침 Claude가 알아서 폴더를 읽고 보고서 초안을 만든다. 내가 할 일은 결과물을 열어서 확인하는 것뿐이다.

이 글에서는 비개발자가 바로 쓸 수 있는 방법을 중심으로 설정 방법을 단계별로 안내한다.

---

## 1. 자동화 방식 3가지 — 내 상황에 맞는 방법을 고른다

Claude Code의 자동화는 현재 세 가지 방식이 있다. 복잡도와 요구 사항이 다르므로 먼저 내 상황에 맞는 방법을 선택한다.

| 방식 | 설명 | 내 PC가 켜져 있어야 하나 | 난이도 | 권장 대상 |
|---|---|---|---|---|
| ① Desktop 예약 작업 | Claude Code 데스크탑 앱에서 설정 | 켜져 있어야 함 | ⭐ 쉬움 | **비개발자 권장** |
| ② CLI `/loop` | 터미널 세션 안에서만 동작 | 켜져 있어야 함 | ⭐⭐ 보통 | 터미널 익숙한 분 |
| ③ Cloud Routines | Anthropic 서버에서 실행. PC 꺼도 됨 | 꺼도 됨 | ⭐⭐⭐ 어려움 | GitHub 사용자 |

이 가이드는 **① Desktop 예약 작업**을 중심으로 진행한다. 설치 과정이 가장 단순하고, 내 로컬 폴더를 직접 다룰 수 있어서 비개발자에게 가장 실용적이다. ③ Cloud Routines는 별도로 마지막 섹션에서 설명한다.

## 2. 준비물 확인

- **Claude Code 데스크탑 앱** 설치 (1편에서 CLI를 설치했다면 별도로 설치 필요)
- **Claude Pro 또는 Max 플랜** ($20 또는 $100/월)
- **자동화할 작업이 담긴 로컬 폴더**

> ⚠️ **Claude Code CLI와 데스크탑 앱은 다른 프로그램이다**
>
> 1~2편에서 설치한 `@anthropic-ai/claude-code`는 터미널 CLI 버전이다. Desktop 예약 작업을 쓰려면 **데스크탑 앱**을 별도로 설치해야 한다. 같은 Claude 계정으로 연동되므로 인증은 다시 하지 않아도 된다.

**데스크탑 앱 설치 방법**

1. `claude.ai`에 접속한 뒤 로그인한다.
2. 상단 메뉴에서 **Claude Code → Download Desktop App**을 클릭한다.
3. 맥은 `.dmg`, 윈도우는 `.exe` 파일을 다운로드해서 설치한다.
4. 설치 후 앱을 실행하고 동일한 Claude 계정으로 로그인한다.

## 3. 실습 준비 — 샘플 폴더와 파일 만들기

지금 당장 따라할 파일이 없어도 된다. 아래 순서대로 샘플 환경을 5분 안에 만들 수 있다.

**Step 1. 작업 폴더 만들기**

바탕화면에 `weekly_logs`라는 폴더를 만든다.

**Step 2. 샘플 로그 파일 3개 만들기**

메모장(윈도우) 또는 텍스트 편집기(맥)로 아래 내용을 입력하고 각각 다른 파일 이름으로 저장한다.

파일 1: `2026-05-05_week.txt`
```
[완료]
- 4월 신규 고객 온보딩 자료 업데이트
- 팀 주간 회의 진행 및 회의록 작성
- Q2 예산 검토 보고서 제출

[진행 중]
- 협력사 계약서 검토 (법무팀 회신 대기)
- 홈페이지 리뉴얼 기획안 초안 작성

[이슈]
- CRM 시스템 접속 오류 발생 (IT 티켓 #2045 접수)
```

파일 2: `2026-05-12_week.txt`
```
[완료]
- 협력사 계약서 최종 서명 완료
- 홈페이지 기획안 팀 내부 공유
- 신입사원 입사 오리엔테이션 진행

[진행 중]
- 6월 마케팅 캘린더 작성 중
- CRM 오류 재현 테스트 (IT팀 협조 중)

[이슈]
- 없음
```

파일 3: `2026-05-19_week.txt`
```
[완료]
- 6월 마케팅 캘린더 확정 및 공유
- 분기 성과 발표 자료 준비

[진행 중]
- 신규 파트너사 제안서 작성

[이슈]
- 제안서 마감일 촉박 (5/22까지). 지원 필요 가능성 있음
```

## 4. 실습 ① — 데스크탑 앱에서 예약 작업 설정

Claude Code 데스크탑 앱을 실행한다.

**Step 1. Schedule 탭 열기**

앱 왼쪽 사이드바에서 **Schedule(예약)** 항목을 클릭한다. 처음 열면 예약된 작업이 없는 빈 화면이 나온다.

**Step 2. 새 작업 만들기**

**+ New task** 버튼을 클릭한다.

**Step 3. 설정 입력**

아래 항목을 입력한다.

- **Name(작업 이름):** `주간 업무 보고서 자동 생성`
- **Working folder(작업 폴더):** `weekly_logs` 폴더 경로를 선택한다
- **Schedule(실행 주기):** `Weekly` → 요일: `Monday` → 시간: `09:00`
- **Prompt(지시 내용):** 아래 내용을 그대로 붙여넣는다

```
weekly_logs 폴더 안에서 이번 주에 해당하는 _week.txt 파일을 읽어줘.
없으면 가장 최근 파일을 읽어줘.

다음 형식으로 주간 보고서 초안을 만들어줘.

# 주간 업무 보고서 — {파일의 날짜 기준 주차}

## 완료된 업무
(완료 항목을 번호 목록으로 정리)

## 진행 중인 업무
(진행 중 항목과 현재 상태를 정리)

## 이슈 및 요청사항
(이슈 항목 정리. 없으면 "해당 없음"으로 작성)

## 다음 주 우선순위 (예상)
(완료된 업무와 진행 중 업무를 바탕으로 다음 주 할 일 3가지를 예측해서 제안)

완성된 보고서는 weekly_report_{오늘날짜}.md 파일로 저장해줘.
```

**Step 4. 저장 및 테스트**

**Create** 버튼을 클릭해서 저장한다. 바로 테스트하려면 **Run now** 버튼을 클릭한다.

작업이 실행되면 앱 하단에 진행 상황이 표시된다. 완료 후 `weekly_logs` 폴더에 `weekly_report_2026-05-14.md` 파일이 생성된다.

---

## 5. 생성된 보고서 결과 확인

폴더에서 생성된 `.md` 파일을 더블클릭하거나, Claude Code 앱 안에서 바로 미리볼 수 있다. 결과물은 대략 다음과 같은 형태다.

```markdown
# 주간 업무 보고서 — 2026년 5월 3주차

## 완료된 업무
1. 6월 마케팅 캘린더 확정 및 팀 공유
2. 분기 성과 발표 자료 준비

## 진행 중인 업무
- 신규 파트너사 제안서 작성 중 (5/22 마감)

## 이슈 및 요청사항
- 제안서 마감일 촉박. 추가 지원 인력 배정 검토 필요

## 다음 주 우선순위 (예상)
1. 파트너사 제안서 완료 및 제출
2. 제안서 결과 후속 미팅 준비
3. 6월 마케팅 캘린더 실행 착수
```

초안이기 때문에 내용을 보완하거나 직접 수정해서 그대로 제출해도 된다.

## 6. 예약 작업 관리

**실행 이력 확인**

Schedule 탭에서 작업 이름을 클릭하면 지금까지 실행된 기록과 각 실행의 결과물을 확인할 수 있다.

**수정이 필요할 때**

작업을 클릭하고 **Edit**을 눌러서 프롬프트나 시간을 수정한다.

**일시 중지**

작업 옆 토글을 끄면 일시 중지된다. 완전히 삭제하지 않아도 된다.

**대화로 수정하기**

데스크탑 앱의 아무 세션에서나 자연어로 지시해도 된다.

```
주간 보고서 예약 작업의 실행 시간을 매주 금요일 오후 5시로 바꿔줘.
```

## 7. 실전 자동화 아이디어 모음

설정 방법을 익혔다면 아래 시나리오를 바로 응용할 수 있다.

**매일 아침 — 오늘 할 일 브리핑**
```
today_tasks.txt 파일을 읽고
오늘 날짜 기준으로 마감이 임박한 항목을 우선순위 순서로 정리해줘.
긴급(오늘 마감), 중요(이번 주 마감), 일반으로 구분해줘.
briefing_{오늘날짜}.md로 저장해줘.
```
→ 실행 주기: Weekdays (평일) 매일 오전 8:30

**매월 초 — 지난 달 완료 업무 통계**
```
logs 폴더에서 지난 달 파일들을 모두 읽고
완료된 업무 총 건수, 카테고리별 분류, 반복된 이슈 패턴을 분석해서
monthly_summary_{연월}.md로 저장해줘.
```
→ 실행 주기: Monthly (매월 1일) 오전 9:00

**매주 금요일 — 팀 공유용 요약본 생성**
```
이번 주 _week.txt 파일을 읽고
외부에 공유할 수 있는 간결한 팀 업데이트 메시지를 작성해줘.
완료 업무 3줄, 다음 주 계획 2줄, 협조 요청 사항으로 구성해줘.
team_update_{날짜}.txt로 저장해줘.
```
→ 실행 주기: Weekly (금요일) 오후 4:00

## 8. 고급 옵션 — Cloud Routines (PC를 켜두지 않아도 된다)

Cloud Routines는 Anthropic이 관리하는 클라우드 인프라에서 실행되는 저장된 Claude Code 설정이다. 내 노트북이 꺼져 있어도 계속 실행된다. 2026년 4월 14일 리서치 프리뷰로 출시됐다.

Desktop 예약 작업과의 가장 큰 차이는 두 가지다.

첫째, **PC가 꺼져 있어도 실행된다.** 출장 중이거나 퇴근 후에도 예약된 작업이 돌아간다.

둘째, **GitHub 저장소가 필요하다.** 현재 Cloud Routines는 로컬 폴더가 아닌 GitHub 레포에 연결된 파일만 처리할 수 있다. 일반 직장인이 로컬 파일을 GitHub에 올리는 과정이 별도로 필요하다.

**Cloud Routines 시작 방법 (간략)**

1. `claude.ai/code`에 접속한다.
2. 왼쪽 메뉴에서 **Routines** 탭을 클릭한다.
3. **+ New Routine** 버튼을 클릭한다.
4. 프롬프트, GitHub 레포, 트리거(Schedule / API / GitHub 이벤트)를 설정한다.
5. **Create** 후 **Run now**로 즉시 테스트한다.

또는 CLI에서 `/schedule` 명령어로 설정할 수도 있다.

```bash
claude
/schedule
```

**Cloud Routines 사용량 한도 (2026년 5월 기준)**

Pro 사용자는 하루 최대 5회, Max 사용자는 15회, Team/Enterprise 사용자는 25회까지 실행할 수 있다. 한도 초과분은 추가 사용량 구매로 처리된다.

로컬 파일만 다루는 일반 직장인에게는 Desktop 예약 작업이 현 시점에서 더 실용적이다. Cloud Routines는 GitHub 레포와 코드 관련 작업이 주가 되는 팀에 적합하다.

## 9. 자주 하는 실수와 해결법

**예약 시간에 작업이 실행되지 않는다**

Desktop 예약 작업은 앱이 실행 중이어야 한다. 앱을 닫으면 예약이 동작하지 않는다. 자동 실행을 원한다면 시스템 시작 프로그램에 Claude Code 데스크탑 앱을 등록해 두면 된다.
- 윈도우: 시작 메뉴 → 시작프로그램 → 앱 추가
- 맥: 시스템 환경설정 → 일반 → 로그인 항목 → 앱 추가

**보고서가 빈 내용으로 생성됐다**

프롬프트에서 지정한 폴더 이름 또는 파일 이름 패턴과 실제 파일이 다른 경우다. 폴더 이름과 파일 이름 규칙이 일치하는지 확인한다.

**이전 보고서와 내용이 너무 비슷하다**

Claude Code는 매 실행 시 새 세션으로 시작하기 때문에 이전 보고서를 참고하지 않는다. 프롬프트에 "이전 보고서와 중복되지 않도록, 이번 주 파일만 기준으로 작성해줘"라는 문장을 추가하면 된다.

## 10. ChatGPT와 무엇이 다른가

| 상황 | ChatGPT | Claude Code 자동화 |
|---|---|---|
| 매주 보고서 생성 | 매주 직접 열고 입력 | 설정 1회 후 자동 실행 |
| 실행 시점 | 내가 요청할 때만 | 예약된 시간에 자동 실행 |
| PC 상태 | 항상 직접 실행 | Desktop: PC 켜짐 유지 / Cloud: PC 꺼도 됨 |
| 결과물 저장 | 직접 복사 저장 | 파일로 자동 저장 |
| 이전 설정 기억 | 매번 새로 작성 | 저장된 작업 재사용 |

세 편에 걸쳐 살펴본 내용을 정리하면 이렇다. 1편은 AI가 내 파일을 읽는 방법, 2편은 AI가 내 파일을 직접 수정하는 방법, 그리고 이번 3편은 AI가 스스로 작동하게 만드는 방법이었다. 이 세 가지를 조합하면 반복 업무의 상당 부분을 AI가 처리하는 구조를 만들 수 있다.
