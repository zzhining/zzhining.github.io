# 데이터 분석가는 ChatGPT에 이렇게 묻는다

ChatGPT로 데이터 분석을 시도해본 적 있는가?

열심히 물어봤는데 뭔가 두루뭉술하고,
원하는 답은 안 나오고,
"내가 뭘 잘못하고 있는 건가" 싶었던 경험 말이다.

사실 그건 ChatGPT의 문제가 아니다.
**프롬프트 설계 방식**의 차이다.

데이터 분석 전문가들은 같은 ChatGPT를 쓰면서도
전혀 다른 방식으로 질문한다.
오늘은 그 차이를 실제 사례와 함께 뜯어본다.
그리고 당장 복붙해서 쓸 수 있는 템플릿도 함께 제공한다.

## 1. 핵심 차이: 결과 요청 vs 분석 설계

일반인은 **결과**를 요청한다.
전문가는 **분석 과정**을 설계해서 넣는다.

이 차이가 왜 중요할까?

ChatGPT는 질문이 모호하면 그냥 그럴듯한 답을 만들어낸다.
데이터 맥락이 없으면 일반적인 이야기를 한다.
분석 목적이 없으면 엉뚱한 방향으로 간다.

전문가는 이 사실을 알기 때문에,
질문 전에 이미 분석의 절반을 스스로 설계하고 들어간다.

---

## 2. 데이터 맥락 제공: 구조를 먼저 설명한다

**일반인 프롬프트**
```
이 데이터 분석해줘.
```

**전문가 프롬프트**
```
다음은 2024년 1월~6월 온라인 쇼핑몰 거래 데이터입니다.
컬럼: 날짜, 고객ID, 성별, 연령대, 상품카테고리, 결제금액, 반품여부, 재구매여부
분석 목적: 반품률이 높은 카테고리의 구매 패턴을 파악하고 싶습니다.
이 목적에 맞는 분석 방향을 먼저 제안해주세요.
```

**왜 다른가?**
ChatGPT는 데이터 구조를 모르면 범용적인 이야기를 할 수밖에 없다.
컬럼명, 기간, 목적을 명시하면 맥락에 맞는 분석이 나온다.

**바로 쓰는 템플릿**
```
다음은 [기간] [업종/서비스명] 데이터입니다.
컬럼 구성: [컬럼1], [컬럼2], [컬럼3], [컬럼4]
분석 목적: [무엇을 알고 싶은지 한 문장]
이 목적에 맞는 분석 방향을 제안해주세요.
```

---

## 3. 분석 단계 직접 설계: AI에게 위임하지 않는다

**일반인 프롬프트**
```
매출이 왜 떨어졌는지 알려줘.
```

**전문가 프롬프트**
```
전월 대비 매출 20% 감소 원인을 파악하려고 합니다.
아래 순서로 분석해주세요.
1) 카테고리별 매출 변화 분해
2) 고객 세그먼트별 구매 빈도 비교 (신규 vs 재구매)
3) 이상치 탐지 후 제외 여부 판단
각 단계의 Python 코드와 해석을 함께 작성해주세요.
```

**왜 다른가?**
"왜 떨어졌는지"는 원인이 수십 가지다.
분석 단계를 직접 설계해서 넣으면
ChatGPT가 그 흐름 안에서만 움직인다.
결과물의 품질이 완전히 달라진다.

**바로 쓰는 템플릿**
```
[분석 목표]를 파악하려고 합니다.
아래 순서로 분석해주세요.
1) [첫 번째 분석 단계]
2) [두 번째 분석 단계]
3) [세 번째 분석 단계]
각 단계의 [Python/SQL] 코드와 해석을 함께 작성해주세요.
```

---

## 4. 가설 먼저 제시: 검증 도구로 쓴다

**일반인 프롬프트**
```
어떤 고객이 많이 사는지 알려줘.
```

**전문가 프롬프트**
```
가설: 30대 여성 고객의 재구매율이 가장 높을 것으로 예상합니다.
이 가설을 검증하기 위해 성별, 연령대, 재구매 여부 컬럼을 활용한
코호트 분석 코드를 Python으로 작성해주세요.
검증 결과에 따라 가설이 기각될 경우의 대안 해석도 함께 제시해주세요.
```

**왜 다른가?**
가설 없이 물으면 ChatGPT는 평균적인 답을 내놓는다.
가설을 먼저 제시하면 검증 설계가 명확해지고,
틀렸을 때의 해석까지 함께 얻을 수 있다.

**바로 쓰는 템플릿**
```
가설: [내가 예상하는 결론을 한 문장으로]
이 가설을 검증하기 위해 [사용할 컬럼명]을 활용한
[분석 방법] 코드를 [Python/SQL]로 작성해주세요.
가설이 기각될 경우의 대안 해석도 함께 제시해주세요.
```

---

## 5. 출력 형식 지정: 보고서 구조를 프롬프트에 넣는다

**일반인 프롬프트**
```
분석 결과 알려줘.
```

**전문가 프롬프트**
```
분석 결과를 아래 형식으로 출력해주세요.
- 요약 인사이트: 3줄 이내
- 근거 테이블: 카테고리 / 반품률 / 전월 대비 증감
- 시각화 코드: matplotlib 기반 막대 그래프
- 추가 분석 추천: 2가지 이내
```

**왜 다른가?**
형식을 지정하지 않으면 ChatGPT는 매번 다른 구조로 답한다.
보고서 형식을 미리 정의하면 결과물을 바로 업무에 붙여넣을 수 있다.

**바로 쓰는 템플릿**
```
분석 결과를 아래 형식으로 출력해주세요.
- 요약 인사이트: [몇 줄 이내]
- 근거 테이블: [컬럼 구성]
- 시각화 코드: [사용할 라이브러리]
- 추가 분석 추천: [몇 가지 이내]
```

## 6. 데이터 한계 명시: 품질을 알고 쓴다

**일반인 프롬프트**
```
이 데이터로 내년 매출 예측해줘.
```

**전문가 프롬프트**
```
현재 데이터 상태: 결측치 15% 존재, 계절성 미반영, 샘플 기간 6개월
이 한계를 명시한 상태에서 단순 선형회귀 기반 예측을 수행해주세요.
예측값과 함께 95% 신뢰구간을 표시하고,
데이터 한계로 인한 예측 신뢰도 주의사항도 포함해주세요.
```

**왜 다른가?**
데이터 품질을 무시하면 그럴듯해 보이는 잘못된 예측이 나온다.
전문가는 한계를 먼저 명시하고, 그 안에서 최선의 결과를 요청한다.

**바로 쓰는 템플릿**
```
현재 데이터 상태: [결측치 비율], [기간], [알려진 한계점]
이 한계를 명시한 상태에서 [분석 방법] 기반 분석을 수행해주세요.
데이터 한계로 인한 해석 주의사항도 함께 포함해주세요.
```

---

## 7. 전문가 프롬프트 패턴 한눈에 정리

| 구분 | 일반인 | 전문가 |
|------|--------|--------|
| 시작점 | 궁금한 것 | 분석 목적 |
| 데이터 설명 | 없음 | 구조·기간·맥락 명시 |
| 분석 방법 | AI에 위임 | 단계별 직접 설계 |
| 가설 | 없음 | 먼저 제시 후 검증 |
| 출력 형식 | 자유 | 보고서 구조 지정 |
| 데이터 한계 | 무시 | 명시적 포함 |

---

ChatGPT를 잘 쓰는 것은 AI를 잘 아는 게 아니다.
**내 문제를 구조화하는 능력**이다.

데이터 전문가들이 좋은 결과를 얻는 이유는
AI가 더 똑똑해서가 아니라,
질문 전에 이미 분석을 설계하기 때문이다.

위의 템플릿 6개를 복붙해서 한 번만 써보자.
같은 ChatGPT가 전혀 다른 결과를 내놓는 걸 직접 확인하게 될 것이다.
