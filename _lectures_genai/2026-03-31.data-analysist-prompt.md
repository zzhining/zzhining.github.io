# 데이터 분석가는 ChatGPT에 이렇게 묻는다

ChatGPT로 데이터 분석을 시도해본 적 있는가?

열심히 물어봤는데 뭔가 두루뭉술하고,
원하는 답은 안 나오고,
"내가 뭘 잘못하고 있는 건가" 싶었던 경험 말이다.

사실 그건 ChatGPT의 문제가 아니다.
**프롬프트 설계 방식**의 차이다.

데이터 분석 전문가들은 같은 ChatGPT를 쓰면서도
전혀 다른 방식으로 질문한다.
오늘은 그 차이를 실제 사례와 함께 뜯어본다.
그리고 당장 복붙해서 쓸 수 있는 템플릿도 함께 제공한다.

> 💡 **실습 데이터 다운로드**  
> 아래 프롬프트를 직접 써볼 수 있는 가상 쇼핑몰 거래 데이터(CSV)를 제공한다.  
> 컬럼 구성: 날짜 / 고객ID / 성별 / 연령대 / 상품카테고리 / 결제금액 / 반품여부 / 재구매여부

## 1. 핵심 차이: 결과 요청 vs 분석 설계

일반인은 **결과**를 요청한다.
전문가는 **분석 과정**을 설계해서 넣는다.

이 차이가 왜 중요할까?

ChatGPT는 질문이 모호하면 그냥 그럴듯한 답을 만들어낸다.
데이터 맥락이 없으면 일반적인 이야기를 한다.
분석 목적이 없으면 엉뚱한 방향으로 간다.

전문가는 이 사실을 알기 때문에,
질문 전에 이미 분석의 절반을 스스로 설계하고 들어간다.

## 2. 데이터 맥락 제공: 구조를 먼저 파악한다

**일반인 프롬프트**
```
이 데이터 분석해줘.
```

**전문가 프롬프트**
```
다음은 2024년 1~6월 온라인 쇼핑몰 거래 데이터다.
분석 목적: 반품률이 높은 카테고리의 구매 패턴 파악

분석 전에 아래 기준으로 데이터 구조를 파악해라.

1) 컬럼명과 데이터 타입 목록 출력 (df.dtypes)
2) 컬럼별 결측치 수 및 비율 (df.isnull().sum())
3) 범주형 컬럼의 유니크값 종류 및 개수 (df[col].value_counts())
4) 수치형 컬럼의 기초 통계량 (df.describe())
5) 전체 행 수, 중복 행 수 확인 (df.shape, df.duplicated().sum())

각 항목을 pandas 코드로 작성하고, 결과를 바탕으로 분석 목적에 맞는 방향 3가지를 제안해라.
```

**왜 다른가?**

현실에서는 데이터를 처음 받는 순간 컬럼이 몇 개인지, 어떤 타입인지조차 모른다. 일반인은 그 상태에서 바로 "분석해줘"를 묻는다. 전문가는 먼저 데이터의 구조를 파악하는 EDA(탐색적 데이터 분석)를 수행한다.

EDA에서 확인하는 항목들은 단순한 절차가 아니다. 이유가 있다.

- **결측치 확인**: 결측치가 많은 컬럼은 분석에서 제외하거나 대체 처리해야 한다. 모르고 쓰면 왜곡된 결과가 나온다.
- **유니크값 확인**: 범주형 컬럼의 유니크값을 모르면 어느 기준으로 그룹화할지 결정할 수 없다. "상품카테고리"에 어떤 값들이 있는지 알아야 카테고리별 분석이 가능하다.
- **기초 통계량 확인**: 수치형 컬럼의 최솟값이 음수라면 데이터 오류다. 최댓값이 극단적으로 크다면 이상치가 있다는 신호다.

이 과정을 프롬프트에 담으면, ChatGPT가 코드를 짜고 실행 결과를 해석해준다. 그 결과를 보고 나서 분석 방향을 결정하는 것이 현실적인 순서다.

**바로 쓰는 템플릿**
```
다음은 [기간] [업종/서비스명] 데이터다.
분석 목적: [무엇을 알고 싶은지 한 문장]

분석 전에 아래 기준으로 데이터 구조를 파악해라.
1) 컬럼명과 데이터 타입 목록
2) 컬럼별 결측치 수 및 비율
3) 범주형 컬럼의 유니크값 종류 및 분포
4) 수치형 컬럼의 기초 통계량
5) 전체 행 수, 중복 행 수 확인

결과를 바탕으로 분석 방향 3가지를 제안해라.
```

## 3. 분석 단계 직접 설계: AI에게 위임하지 않는다

**일반인 프롬프트**
```
매출이 왜 떨어졌는지 알려줘.
```

**전문가가 프롬프트를 쓰기 전에 하는 것**

전문가는 프롬프트를 쓰기 전에 먼저 머릿속에서 원인 트리를 그린다.

"매출이 20% 감소했다"는 현상이 있을 때, 원인을 바로 찾으려 하지 않는다. 먼저 숫자를 쪼갠다.

> 매출 = 거래 건수 × 평균 결제금액

건수가 줄었는가, 아니면 금액이 줄었는가? 이 두 가지는 원인도 해결책도 전혀 다르다.

- **건수가 줄었다면** → 어떤 카테고리에서 줄었는가? 어떤 고객군이 이탈했는가?
- **금액이 줄었다면** → 고가 상품 구매가 줄었는가? 할인/반품이 늘었는가?

이 분기점을 먼저 설계한 다음, 각각을 검증할 분석 단계로 변환한다. 그것이 프롬프트가 된다.

**전문가 프롬프트**
```
전월 대비 매출 20% 감소 원인을 파악한다.
아래 순서로 분석해라.

1) 카테고리별 매출 변화 분해
   - 이번 달과 전월의 카테고리별 거래 건수, 합계 금액을 비교한다.
   - 가장 큰 변화가 있는 카테고리를 특정한다.

2) 고객 세그먼트별 구매 빈도 비교 (신규 vs 재구매)
   - 신규 고객과 재구매 고객 각각의 건수 변화를 확인한다.
   - 이탈이 집중된 세그먼트가 있는지 파악한다.

3) 이상치 탐지 후 제외 여부 판단
   - 결제금액 기준 상위 1% 거래를 추출한다.
   - 전월에만 있던 대형 거래가 이번 달 수치에 영향을 주는지 확인한다.

각 단계의 Python 코드와 해석을 함께 작성해라.
```

**왜 다른가?**

"왜 떨어졌는지"는 원인이 수십 가지다. ChatGPT에 그냥 물으면 가능한 원인을 나열하거나, 임의의 방향으로 분석을 시작한다. 그 결과는 분석자의 판단이 아닌 AI의 추측이다.

분석 단계를 직접 설계해서 프롬프트에 넣으면, ChatGPT는 그 흐름 안에서만 움직인다. 내가 설계한 가설 검증 경로를 따라 코드를 생성하고 해석을 붙인다. 결과물의 방향성과 품질이 완전히 달라진다.

핵심은 프롬프트를 쓰기 전에 "이 현상의 원인은 무엇일 수 있는가"를 스스로 먼저 생각하는 것이다. 그 사고의 결과물이 분석 단계가 된다.

**바로 쓰는 템플릿**
```
[분석 목표]를 파악한다.
아래 순서로 분석해라.

1) [첫 번째 단계]: [무엇을 비교하거나 확인하는지 구체적으로]
2) [두 번째 단계]: [무엇을 비교하거나 확인하는지 구체적으로]
3) [세 번째 단계]: [무엇을 비교하거나 확인하는지 구체적으로]

각 단계의 [Python/SQL] 코드와 해석을 함께 작성해라.
```

## 4. 가설 먼저 제시: 검증 도구로 쓴다

**일반인 프롬프트**
```
어떤 고객이 많이 사는지 알려줘.
```

**가설이란 무엇인가**

데이터 분석에서 가설이란 **"내가 예상하는 결론"**이다. 분석을 시작하기 전에 "아마 이럴 것이다"를 먼저 한 문장으로 써두는 것이다.

"어떤 고객이 많이 사는지"를 물으면 ChatGPT는 나이별, 성별별, 지역별, 구매 시간대별로 다 보여준다. 어디에 집중해야 하는지 알 수 없다. 방향이 없으니 모든 방향을 보여주는 것이다.

반면 "30대 여성의 재구매율이 가장 높을 것 같다"고 먼저 말하면, ChatGPT는 이 예측을 검증할 방법을 설계한다. 어떤 컬럼을, 어떤 방법으로, 어떤 기준으로 비교할지가 구체적으로 결정된다.

**"가설을 먼저 말하면 ChatGPT가 그 방향으로만 답하지 않나?"** 라는 의문이 생길 수 있다. 그래서 프롬프트 마지막에 "가설이 기각될 경우의 대안 해석도 제시해라"를 함께 넣는다. 이 한 문장이 편향 없는 검증을 보장한다.

가설은 확신이 아니다. 틀려도 된다. 오히려 틀렸을 때 새로운 발견이 생기고, 그것이 더 유의미한 인사이트가 되는 경우가 많다.

**전문가 프롬프트**
```
가설: 30대 여성 고객의 재구매율이 가장 높다.
이 가설을 검증하기 위해 성별, 연령대, 재구매여부 컬럼을 활용한
코호트 분석 코드를 Python으로 작성해라.
가설이 기각될 경우 실제로 재구매율이 높은 집단과 그 이유도 함께 해석해라.
```

> 💡 **코호트 분석이란?**  
> 특정 기준(가입 시기, 첫 구매월, 성별+연령대 등)으로 묶은 고객 집단(코호트)의 행동을 비교하는 분석 방법이다.  
> 여기서는 **성별 × 연령대** 조합을 코호트 단위로 삼아, 각 집단의 재구매 비율을 비교한다.

**왜 다른가?**

가설이 없으면 분석 방향이 없다. ChatGPT는 가능한 모든 방향을 나열하거나, 임의의 방향을 선택한다. 어느 쪽이든 원하는 답이 나오지 않는다.

가설이 있으면 검증 설계가 구체적으로 결정된다. "30대 여성의 재구매율"을 검증하려면 성별과 연령대를 기준으로 그룹을 나누고, 각 그룹의 재구매여부를 집계하는 코드가 필요하다. ChatGPT는 이 구조를 그대로 따른다.

데이터 분석의 기본 흐름은 **가설 → 검증 → 결론**이다. 이 흐름을 프롬프트에 그대로 담는 것이 전문가 방식이다.

**바로 쓰는 템플릿**
```
가설: [내가 예상하는 결론을 한 문장으로]
이 가설을 검증하기 위해 [사용할 컬럼명]을 활용한
[분석 방법] 코드를 [Python/SQL]로 작성해라.
가설이 기각될 경우 실제 결과와 그 이유도 함께 해석해라.
```

## 5. 출력 형식 지정: 보고서 구조를 프롬프트에 넣는다

**일반인 프롬프트**
```
분석 결과 알려줘.
```

**전문가 프롬프트**
```
분석 결과를 아래 형식으로 출력해라.

- 요약 인사이트: 3줄 이내 (각 줄에 수치 포함)
- 근거 테이블: 카테고리 / 반품률 / 전월 대비 증감 순서로 출력
- 시각화: 아래 조건으로 SVG 파일을 생성해라.
  - 캔버스 크기: 1280×720px (16:9 비율, 슬라이드 삽입용)
  - 차트 종류: 카테고리별 반품률 가로 막대 그래프
  - 색상: 반품률 상위 항목은 #E74C3C (레드), 나머지는 #BDC3C7 (그레이)
  - 배경색: #FFFFFF
  - 제목 폰트: 18px, bold, #2C3E50
  - 축 레이블: 13px, #555555
  - 여백: 상 40px / 하 60px / 좌 80px / 우 40px
  - 출력 파일명: return_rate_by_category.svg
- 추가 분석 추천: 2가지 이내
```

**왜 다른가?**

형식을 지정하지 않으면 ChatGPT는 매번 다른 구조로 답한다. 텍스트로만 나오기도 하고, 갑자기 표가 나오기도 한다. 같은 분석을 여러 번 돌려도 결과물의 형태가 달라진다.

출력 형식을 미리 정의하면 달라진다. 항상 같은 구조로 결과가 나오기 때문에 바로 업무에 사용할 수 있다.

특히 시각화를 SVG로 지정하는 이유가 있다. SVG는 벡터 형식이라 어떤 크기로 확대해도 깨지지 않는다. PNG나 JPG는 슬라이드에 넣으면 흐릿해지지만, SVG는 4K 화면에서도 선명하다. 16:9 캔버스 크기(1280×720)를 지정하면 발표 슬라이드에 그대로 삽입할 수 있다.

색상과 폰트를 지정하는 이유도 명확하다. ChatGPT가 임의로 선택한 색상 조합은 가독성이 낮거나 회사 브랜드 컬러와 다를 수 있다. 처음부터 규격을 주면 수정 없이 바로 쓸 수 있는 결과물이 나온다.

**바로 쓰는 템플릿**
```
분석 결과를 아래 형식으로 출력해라.

- 요약 인사이트: [몇 줄 이내] (수치 포함)
- 근거 테이블: [컬럼 구성]
- 시각화:
  - 캔버스 크기: 1280×720px (16:9)
  - 차트 종류: [막대/선/산점도 등]
  - 색상: 강조 항목 [hex코드], 일반 항목 [hex코드]
  - 제목 폰트: [크기]px, bold
  - 출력 파일명: [파일명].svg
- 추가 분석 추천: [몇 가지 이내]
```

## 6. 데이터 한계 명시: 품질을 알고 쓴다

**일반인 프롬프트**
```
이 데이터로 내년 매출 예측해줘.
```

**전문가 프롬프트**
```
현재 데이터 상태: 결측치 15% 존재, 계절성 미반영, 샘플 기간 6개월
이 한계를 명시한 상태에서 단순 선형회귀 기반 예측을 수행해주세요.
예측값과 함께 95% 신뢰구간을 표시하고,
데이터 한계로 인한 예측 신뢰도 주의사항도 포함해주세요.
```

**왜 다른가?**
데이터 품질을 무시하면 그럴듯해 보이는 잘못된 예측이 나온다.
전문가는 한계를 먼저 명시하고, 그 안에서 최선의 결과를 요청한다.

**바로 쓰는 템플릿**
```
현재 데이터 상태: [결측치 비율], [기간], [알려진 한계점]
이 한계를 명시한 상태에서 [분석 방법] 기반 분석을 수행해주세요.
데이터 한계로 인한 해석 주의사항도 함께 포함해주세요.
```

## 7. 전문가 프롬프트 패턴 한눈에 정리

| 구분 | 일반인 | 전문가 |
|------|--------|--------|
| 시작점 | 궁금한 것 | 분석 목적 |
| 데이터 설명 | 없음 | 구조·기간·맥락 명시 |
| 분석 방법 | AI에 위임 | 단계별 직접 설계 |
| 가설 | 없음 | 먼저 제시 후 검증 |
| 출력 형식 | 자유 | 보고서 구조 지정 |
| 데이터 한계 | 무시 | 명시적 포함 |

---

ChatGPT를 잘 쓰는 것은 AI를 잘 아는 게 아니다.
**내 문제를 구조화하는 능력**이다.

데이터 전문가들이 좋은 결과를 얻는 이유는
AI가 더 똑똑해서가 아니라,
질문 전에 이미 분석을 설계하기 때문이다.

위의 템플릿 6개를 복붙해서 한 번만 써보자.
같은 ChatGPT가 전혀 다른 결과를 내놓는 걸 직접 확인하게 될 것이다.
