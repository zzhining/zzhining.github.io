## 소프트웨어엔지니어링 강의 자료

소프트웨어 개발 전반에 걸친 실무 중심의 강의 자료입니다.

### 주요 주제

- **버전 관리**: Git, GitHub 협업 워크플로우
- **개발 환경**: Docker, 가상환경, 패키지 관리
- **API 개발**: REST API, FastAPI, Django REST Framework
- **테스트**: 단위 테스트, 통합 테스트, pytest
- **CI/CD**: GitHub Actions, 자동 배포 파이프라인
- **클라우드**: AWS, GCP 기본 서비스 활용
- **코드 품질**: 클린 코드, 리팩토링, 코드 리뷰
