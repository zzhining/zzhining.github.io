## 대시보드 생성 강의 자료

Streamlit, Tableau, Power BI 등을 활용하여 인터랙티브 데이터 대시보드를 만드는 강의 자료입니다.

### 주요 주제

- **Streamlit**: 파이썬으로 웹 대시보드 빠르게 구축
- **Plotly Dash**: 인터랙티브 시각화 대시보드
- **Tableau**: 비즈니스 인텔리전스 대시보드
- **Power BI**: Microsoft 데이터 시각화 도구
- **Grafana**: 모니터링 및 분석 대시보드
- **Google Data Studio**: 무료 BI 도구 활용

### 실습 코드

강의 실습 코드는 [GitHub](https://github.com/zzhining)에서 확인하실 수 있습니다.
