## 파이썬 기초 강의 자료

프로그래밍 입문자를 위한 파이썬 기초 강의 자료입니다.
기본 문법부터 실전 활용까지 단계적으로 학습할 수 있습니다.

### 주요 주제

- **파이썬 설치 및 환경 설정**: Anaconda, VS Code, Jupyter Notebook
- **기본 문법**: 변수, 자료형, 조건문, 반복문
- **함수와 모듈**: 함수 정의, 내장 함수, 외부 라이브러리
- **파일 입출력**: 텍스트, CSV, JSON 파일 처리
- **객체지향 프로그래밍**: 클래스, 상속, 다형성
- **예외 처리**: try-except, 에러 핸들링
