## 데이터분석 강의 자료

Pandas, NumPy를 활용한 데이터 분석 강의 자료입니다.
실제 데이터셋을 활용한 실습 중심의 내용을 담고 있습니다.

### 주요 주제

- **데이터 수집**: 웹 스크래핑, API 활용, 공공 데이터 활용
- **데이터 전처리**: 결측값 처리, 이상값 탐지, 데이터 정제
- **탐색적 데이터 분석(EDA)**: 통계 분석, 상관관계 분석
- **데이터 시각화**: Matplotlib, Seaborn, Plotly
- **통계 분석**: 가설 검정, 회귀 분석
- **SQL 데이터 분석**: 쿼리 최적화, 집계 분석

### 실습 코드

강의 실습 코드는 [GitHub](https://github.com/zzhining)에서 확인하실 수 있습니다.
